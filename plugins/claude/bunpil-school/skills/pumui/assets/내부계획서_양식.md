# ○○ 물품 구입 내부계획서

1. 목적
   - (예: 2학기 ○○ 수업 운영에 필요한 물품을 구입하여 …)
2. 근거
   - (사용자가 알려 준 계획·지침 이름. 없으면 '확인 필요')
3. 소요예산
   - 금○○,○○○원(금○○○○원)  (학교회계 ○○비, 예산과목 확인 필요)
4. 산출내역
   - 1) 품명 규격 @단가 × 수량 = 금액
   - 2) …
   - 소계 ○○원 + 배송비 ○○원 = 합계 ○○원
5. 기대효과
   - (목적과 연결된 효과 2~3개. 수치는 근거가 있을 때만)
6. 확인 필요
   - 자산/소모품 구분, 예산과목, 견적 절차
