# 품의 도우미

학교 예산으로 물품을 사기 위한 품의 서류 초안을 만든다. 특정 쇼핑몰에 의존하지 않는다.

원안: 날쌤(몽당분필)의 G마켓 물품 품의 워크플로(품목별 상품 선정 → 장바구니 → 가격 근거 → 산출내역·내부계획서)를 일반화했다.

## 시작 전

- 작업 폴더의 `CLAUDE.md` 또는 `AGENTS.md`를 읽어 학교·부서·문체를 반영한다. 없으면 필요한 것만 짧게 묻는다.
- 학교 서식(내부계획서 양식, 학교회계 예산편성 기본지침)이 폴더에 있으면 읽고 따른다. 없으면 `assets/내부계획서_양식.md`를 기본으로 쓴다.

## 개인정보 원칙

학생 실명·학번·생년월일·주소·연락처·가족관계·사진 등 개인을 알아볼 수 있는 정보가 보이면 작업을 멈추고 '학생A'처럼 가명으로 바꾸자고 제안한다. 결과물에는 개인정보를 넣지 않는다.

- 학교 계정 아이디·비밀번호, 카드·계좌 번호는 입력받지도 기록하지도 않는다.

## 초안 규칙과 원본 보호

- 모든 결과는 초안이다. 기안 상신·결재·구매 결정은 교사와 학교가 한다.
- 입력 품목표 원본은 고치지 않는다. 확정본은 `outputs/품목내역_확정.csv`(또는 xlsx) 같은 새 파일로 저장한다. 채팅 전용 환경이면 대화에 표로 제시한다.

## 입력

| 필요 | 내용 |
|---|---|
| 품목표 | 품명, 규격, 단가, 수량(배송비 선택). xlsx/csv/붙여넣기 |
| 예산 | 배정 예산 금액(없으면 합계만 낸다) |
| 목적 | 어떤 교육활동에 쓰는지 한두 문장 |
| 근거 | 관련 계획·지침이 있으면 이름 |

단가가 비었으면 만들지 않고 '확인 필요'로 표시한다. 추정 단가를 채우려면 사용자 동의를 받고 "추정"이라고 표시한다.

## 절차

1. **품목 확인**: 품목표를 읽어 열 구조를 확인한다. 규격이 모호한 품목은 용도와 규격(인치, 용량, 매수 등)을 되묻는다.
2. **산출내역 계산**: `scripts/calc.py`로 계산한다(파이썬이 없으면 직접 계산하고 두 번 검산한다).
   ```
   python3 scripts/calc.py items.csv --budget <배정 예산> --asset-threshold <학교 기준 금액>
   ```
   입력 CSV 열은 `품명,규격,단가,수량[,배송비]`. 출력은 `품명 규격 @단가 × 수량 = 금액` 형식 줄, 소계·배송비·합계, 예산 대조다.
   - `--asset-threshold`는 기본값이 없다. 학교회계 예산편성 기본지침 등에서 학교 기준 금액을 확인한 뒤 그 값을 지정한다. 문서나 예시에 보이는 숫자(예: 300000)는 예시일 뿐이며 학교 기준이 아니다. 기준을 모르면 이 옵션을 빼고 질문으로 남긴다.
   - 단가나 수량이 비었거나 숫자가 아닌 품목이 있으면 그 품목을 합계에서 빼고 `[확인 필요]`를 출력한 뒤 종료 코드 1로 끝난다. 이것은 오류나 실행 실패가 아니라 의도된 동작이다. 출력은 정상이므로 그대로 쓰고, 누락 품목을 사용자에게 알린다.
3. **예산 대조**: 합계가 예산 이내인지, 초과면 얼마나 초과인지 적고 줄일 후보 품목을 제안만 한다(임의로 빼지 않는다).
4. **자산/소모품 구분 질문**: `references/asset-questions.md`의 질문으로 사용자에게 확인한다. 기준 단가·내구연한은 학교회계 예산편성 기본지침에 따르며, 지침을 못 읽었으면 기준 금액을 단정하지 않고 '확인 필요'로 둔다.
5. **내부계획서 초안**: `assets/내부계획서_양식.md`를 바탕으로 목적·근거·소요예산·산출내역·기대효과를 채운다. 근거는 사용자가 알려 준 것만 쓴다.
6. **(선택) 가격 근거 확인**: 아래 "브라우저 단계"를 따른다.

## 브라우저 단계 (선택)

브라우저를 조작할 수 있는 환경에서 사용자가 원할 때만 한다.

- 검색어는 `용도 + 규격`으로 만든다. 예: "보조배터리 20000mAh", "컴퓨터 모니터 보안필름 27인치".
- 쿠폰 적용가(실제 결제가), 배송비(조건부 무료 포함), 판매자 신뢰도, 영수증·세금계산서 발행 가능 여부, 규격 일치를 본다.
- 확인한 단가·수량·배송비·상품 주소·확인 일시를 품목표에 기록한다. 가격은 수시로 바뀌므로 날짜를 함께 남긴다.
- **로그인은 대신 하지 않는다.** 로그인이 필요하면 사용자가 직접 하도록 요청하고 기다린다.
- **결제하지 않는다.** 장바구니에 담는 데까지만 하고, 구매하기·결제 화면으로 들어가지 않는다.
- 장바구니 화면을 가격 근거로 저장하도록 사용자에게 안내한다(캡처 파일명 예: `YYYY-MM-DD_품목명.png`).

## 결과물

- `outputs/산출내역_초안.md`: 산출내역 줄, 합계, 예산 대조
- `outputs/내부계획서_초안.md`: 양식에 채운 초안
- `outputs/확인필요_질문.md`: 자산/소모품 구분 질문, 누락 단가, 예산 초과 항목

## 점검

- [ ] 모든 줄이 `품명 규격 @단가 × 수량 = 금액` 형식이고 금액 합이 합계와 원 단위까지 맞는가
- [ ] 단가·수량 누락 품목을 합계에서 빼고 '확인 필요'로 표시했는가(calc.py 종료 코드 1은 정상 동작)
- [ ] 합계를 예산과 대조해 초과 여부를 적었는가
- [ ] 자산/소모품 구분을 단정하지 않고 질문으로 남겼는가
- [ ] 가격 근거에 확인 날짜가 있고, 로그인·결제를 하지 않았는가
- [ ] 모든 파일에 '초안'이 표시되고 원본 품목표가 그대로인가
