# 살아있는 PPT 만들기 (live-pptx)

슬라이드 안에서 HTML이 **실제로 실행되는** PowerPoint 파일을 만든다. 그림이 아니라 웹 페이지라서 교사와 학생이 화면을 눌러 볼 수 있다.

원리는 세 줄이다. ① 수업 내용을 HTML 한 파일(덱)로 쓴다. ② 변환 스크립트가 그 HTML을 pptx 파일 **안에** 저장하고, 슬라이드마다 "Live HTML" 추가 기능 틀을 놓는다. ③ 발표 PC의 PowerPoint가 그 틀에서 HTML을 꺼내 실행한다.

개인정보 원칙: 학생 실명·학번·생년월일·주소·연락처·가족관계·사진 등 개인을 알아볼 수 있는 정보가 보이면 작업을 멈추고 '학생A'처럼 가명으로 바꾸자고 제안한다. 결과물에는 개인정보를 넣지 않는다.

## 먼저 알릴 것 (만들기 전에 교사에게 말한다)

어느 PowerPoint에서 어디까지 되는지는 실제 PowerPoint(Windows)로 확인한 것만 적는다.

| 발표 PC의 PowerPoint | 편집 화면 | 슬라이드 쇼 |
|---|---|---|
| **Microsoft 365**(구독형, 최신 채널에서 확인) | 눌러진다 | **눌러진다**(클릭·입력·넘기기 모두) |
| Office LTSC 2021·2024(학교·기관이 한꺼번에 설치한 고정판) | 눌러진다 | 화면만 보인다. 눌러지지 않는다 |
| Office 2019(한꺼번에 설치한 판) | 미리보기 그림과 안내 줄 | 같다 |
| Office 2016, Mac, 웹용 PowerPoint, 낱개로 산 Office 2021·2024, 업데이트를 늦춘 Microsoft 365 | 확인하지 못함 | 확인하지 못함 |

- 버전은 PowerPoint의 **파일 → 계정 → 제품 정보**에서 본다. "Microsoft 365"라고 나오면 구독형이다. 확인한 Microsoft 365는 Windows의 최신 채널 16.0.20625(한국어판) 한 빌드뿐이라, 기관이 업데이트를 늦춘 곳은 **발표 전에 슬라이드 쇼로 한 번 눌러 본다.**
- Office 2016은 시험하지 못했다. 같은 옛 웹 엔진이면 그림만 보일 것으로 예상하지만 교사 컴퓨터에서 한 번 열어 확인하게 한다.
- 발표할 컴퓨터마다 추가 기능을 **한 번** 등록한다(5단계). 등록하지 않은 컴퓨터에서는 미리보기 그림 위에 노란 "추가 기능 오류" 줄이 뜬다.
- 화면이 움직이려면 발표할 때 **인터넷**이 연결되어 있어야 한다.
- **슬라이드 쇼에서 눌러 쓸 수 없는 컴퓨터에서는 같은 덱을 브라우저로 띄워 발표한다.** Edge·Chrome으로 열고 F11(전체 화면), ← → 로 넘긴다. 그래서 pptx와, 그림·글자를 한 파일에 합친 `deck-browser.html`을 **항상 함께** 전달한다(3단계에서 변환기가 만든다. `deck.html`은 그림·CSS를 따로 두면 그 파일만 옮겼을 때 그림이 깨진다).
- 휴대폰·태블릿 앱, 한쇼·구글 슬라이드, PDF·인쇄에서는 pptx에 든 미리보기 그림이 보일 것으로 예상한다(확인하지 못함).

교사가 원하는 것이 브라우저로 띄우는 자료뿐이면 pptx를 만들지 않고 덱만 만들어도 된다. 글과 그림만 있으면 되는 수업은 class-slides를 권한다.

## 들어 있는 파일

`<스킬 폴더>`는 이 SKILL.md가 있는 폴더다.

| 파일 | 하는 일 |
|---|---|
| `assets/deck-template.html` | 시작 틀(5학년 수학 "크기가 같은 분수" 6장: 표지·뒤집는 카드·슬라이더 조작·퀴즈·타이머와 번호 뽑기·정리) |
| `scripts/build_live_pptx.py` | HTML → pptx 변환(로컬 그림·CSS·JS 합치기, 미리보기 촬영, 발표자 노트) |
| `scripts/qa_live_pptx.py` | 만든 pptx 점검 |
| `scripts/register_addin.py` | 이 컴퓨터의 PowerPoint에 추가 기능 등록·해제·상태 확인 |
| `assets/manifest.xml` | 추가 기능 설정 파일(등록할 때 쓴다) |
| `references/deck-guide.md` | 덱 HTML 규칙, 활동 부품, 가진 HTML을 바꾸는 방법 |
| `references/troubleshooting.md` | 다른 컴퓨터에 등록하기, 화면이 안 움직일 때, 지울 때 |

## 1. 시작 전 확인

1. 작업 폴더의 `CLAUDE.md` 또는 `AGENTS.md`를 읽어 학교급·학년·교과·문체·선호 색을 반영한다.
2. **빠진 것만** 한 번에 묻는다(최대 4문항): ① 학년·교과·단원과 차시 목표 ② 장수(기본 6~8장)와 넣고 싶은 활동(퀴즈·조작·타이머·뽑기·카드) ③ 발표할 컴퓨터(Windows/Mac, PowerPoint 버전, 수업 중 인터넷) ④ 이미 가진 HTML이 있는지.
3. 교과서 쪽이나 자료를 받았으면 요약·재구성한다. 본문과 삽화를 통째로 옮기지 않고, 못 읽은 부분은 추측하지 않는다.

## 2. 덱 HTML 쓰기

1. `assets/deck-template.html`을 `outputs/<이름>/deck.html`로 복사한다.
2. 구성안(장 제목 + 그 장에서 누르는 것)을 먼저 보여 준다. 교사가 바로 만들어 달라고 했으면 구성안을 보여 주고 이어서 만든다.
3. 규칙은 `references/deck-guide.md`를 따른다. 꼭 지킬 것:
   - 슬라이드 하나 = `<section class="slide">` 하나. 한 장에 학생 활동은 하나만 둔다(타이머·번호 뽑기 같은 교사 도구는 함께 둘 수 있다). 슬라이드끼리는 값을 주고받지 못한다.
   - 맨 아래 "공통 스크립트"는 지우지 않는다.
   - 글꼴·그림·스크립트를 인터넷 주소에서 불러오지 않는다. 필요한 파일은 내려받아 덱 옆에 두면 변환기가 합쳐 준다.
   - 교사 발문은 모든 장의 `data-notes="…"`에 쓴다. **정답은 노트에 쓰고, 누르기 전 첫 화면에는 보이지 않게 한다**(첫 화면이 미리보기 그림이 된다).
   - 퀴즈는 정답 번호와 해설이 문제와 맞는지 하나씩 다시 계산해 확인한다. 도구는 틀린 정답을 잡아 주지 않는다.
   - PowerPoint 안에서는 HTML 글자를 고칠 수 없다. "이름을 적어 주세요"처럼 나중에 손으로 채울 자리를 남기지 않는다.
   - 번호 뽑기는 번호만 쓴다. 학생 이름 목록을 덱에 넣지 않는다.
4. 이미 가진 HTML을 바꿀 때는 `references/deck-guide.md`의 "가진 HTML을 살아있는 덱으로 바꾸기"를 따른다. 원본은 고치지 않고 사본으로 작업한다.

## 3. 변환

```bash
python <스킬 폴더>/scripts/build_live_pptx.py outputs/<이름>/deck.html -o outputs/<이름>/<이름>.pptx --shots outputs/<이름>/preview --save-html outputs/<이름>/deck-browser.html --strict
```

- `python`이 없으면 Windows는 `py`, Mac·Linux는 `python3`을 쓴다. `python-pptx`가 없다는 오류가 나면 "변환에 필요한 파이썬 꾸러미 python-pptx를 설치합니다"라고 알리고 `pip install python-pptx`로 설치한다(막히면 `pip install --user python-pptx`).
- 미리보기 그림은 컴퓨터의 Edge·Chrome으로 찍는다. 못 찾으면 안내 그림으로 대신하므로 `--browser "<실행 파일 경로>"`를 준다.
- `--strict`를 주면 **"주의:" 줄이 하나라도 있을 때 종료 코드 1**로 끝난다(pptx는 만들어진다). 주의 줄을 하나씩 고치고 다시 변환한다: 찾지 못한 파일, 덱 폴더 밖이라 넣지 않은 파일, 합치지 못한 참조, 인터넷에서 불러오는 주소, 슬라이드를 열 때 난 스크립트 오류, 모든 장의 첫 화면이 같음, 찍지 못한 미리보기.
- `--save-html`은 그림·CSS·스크립트를 한 파일로 합친 브라우저용 HTML(`deck-browser.html`)을 만든다. 이 파일을 pptx와 함께 전달한다.
- `--shots`를 주면 장마다 첫 화면 PNG와 모아보기 `sheet.jpg`가 저장된다. **전부 열어 본다**: 겹침·잘림·글자 넘침·빈 화면·낱말 중간 줄바꿈이 없는지. 도구는 화면 아래로 잘린 내용이나 깨진 그림을 알려 주지 못하므로 이 눈으로 보는 점검이 마지막 관문이다. 첫 화면만 찍히므로 눌러서 바뀌는 화면은 4단계에서 본다.
- HTML이 너무 크면(저장 크기 3.0MB 초과) 종료 코드 3으로 멈춘다. 큰 그림을 줄이거나 덱을 나눈다.
- 슬라이드 쇼에서 화면이 실행되지 않는 곳(등록 안 된 PC, LTSC, 옛 Office)에서는 보통 PPT처럼 클릭하면 다음 장으로 넘어간다. 클릭으로는 넘어가지 않게 하려면 `--no-click-advance`를 준다.

## 4. 브라우저로 먼저 보기

`deck-browser.html`을 브라우저로 열어 ← → 키로 넘기며 **모든 단추·슬라이더·입력칸을 눌러 본다.** 여기서 안 되는 것은 PowerPoint에서도 안 된다.

- 브라우저를 조작할 수 있는 도구가 있으면 직접 한다: 장마다 누를 수 있는 것을 모두 누르고, 누른 뒤의 화면을 찍어 글자 겹침·넘침을 보고, 콘솔 오류가 없는지 본다.
- 도구가 없으면 교사에게 `deck-browser.html`을 열어 눌러 봐 달라고 부탁하고, 확인하지 못했다고 전달 때 적는다.

## 5. 추가 기능 등록 (발표할 컴퓨터마다 한 번)

등록은 컴퓨터 설정을 바꾸는 일이므로 **무엇을 하는지 말하고 동의를 받은 뒤** 한다: "지금 로그인한 사용자에게만, 관리자 권한 없이 PowerPoint 추가 기능 한 개를 등록합니다. 프로그램을 설치하지 않고, 언제든 지울 수 있습니다. 발표할 때 인터넷이 필요합니다."

**지금 작업하는 곳이 발표할 컴퓨터일 때**(교사 PC에서 직접 실행 중):

```bash
python <스킬 폴더>/scripts/register_addin.py            # 등록
python <스킬 폴더>/scripts/register_addin.py --status   # 확인
python <스킬 폴더>/scripts/register_addin.py --remove   # 지우기
```

**그렇지 않을 때**(웹·클라우드에서 작업 중이거나, 발표는 교실 PC에서 할 때): 스크립트를 실행하지 않는다. `references/troubleshooting.md`의 "다른 컴퓨터에 등록하기"에 있는 한 줄 명령을 그대로 전달해 발표할 컴퓨터에서 실행하게 한다.

등록한 뒤에는 **PowerPoint를 완전히 종료했다가 다시 연다.**

## 6. 전달

pptx와 `deck-browser.html`의 위치를 함께 알리고 짧게 덧붙인다.

- 장수와 장마다 누를 수 있는 것, 발표자 노트 유무
- 발표 PC 준비: 등록, 인터넷, PowerPoint 버전(Microsoft 365가 아니면 슬라이드 쇼에서는 눌러지지 않으니 `deck-browser.html`을 브라우저로 띄운다)
- 쓰는 법 세 가지: 넘기기는 ← → 또는 화면의 ← → 단추 / 화면을 누른 뒤 쇼를 끝낼 때는 Esc를 두 번 / 수업 전에 눌러 본 장은 ↺ 단추로 처음 상태로 돌린다(파일을 닫았다 다시 열어도 된다)
- 확인하지 못한 것. **실제 PowerPoint에서 열어 보는 마지막 확인은 교사가 한다**(슬라이드 쇼로 모든 장을 한 번씩 눌러 본다).

화면이 움직이지 않으면 `references/troubleshooting.md`를 읽고 증상에 맞는 항목을 안내한다.

## 지켜야 할 원칙

- 결과물은 모두 **초안**이다. 수업에서 쓰기 전 내용·정답·동작 확인은 교사가 한다.
- 원본 파일은 고치지 않는다. 결과는 `outputs/` 아래 새 파일로 저장한다. 채팅 전용 환경이면 덱 HTML을 대화에 제시하고 변환 방법을 안내한다.
- HTML은 pptx 파일 안에 저장되고, 추가 기능 페이지는 덱 내용을 어디로도 보내지 않는다. 그래도 파일을 받는 사람은 안의 HTML을 볼 수 있으므로 공개하면 안 되는 내용을 넣지 않는다.
- 사실·수치·정답은 교사가 준 자료에서 확인된 것만 쓴다. 확인 못 한 내용은 "확인 필요"로 표시한다.
- 교과서 본문·삽화, 저작권 있는 캐릭터, 출처를 모르는 인터넷 그림을 넣지 않는다. 출처는 화면 아래에 `참고: ○○ 교과서 ○쪽`으로 적는다.
- 컴퓨터에 새로 설치·등록할 때는 이름과 이유를 말하고 동의를 받는다. 관리자 권한이 필요한 일은 직접 하지 않고 정보 담당 선생님께 안내한다.

## 점검

- [ ] `python <스킬 폴더>/scripts/qa_live_pptx.py outputs/<이름>/<이름>.pptx` 가 **오류 0건, 주의 0건**인가(남은 주의는 하나씩 설명할 수 있어야 한다)
- [ ] `--strict` 변환이 종료 코드 0으로 끝났고, 슬라이드 수가 `<section class="slide">` 수와 같은가
- [ ] 미리보기 모아보기(`sheet.jpg`)를 전부 봤는가 — 겹침·잘림·빈 화면이 없고, 첫 화면에 정답이 보이지 않으며, 무엇을 하는 장인지 알 수 있는가
- [ ] 브라우저에서 모든 장의 단추·슬라이더·입력이 동작했는가(직접 못 했으면 교사에게 부탁하고 그렇게 적었는가)
- [ ] 모든 장에 발표자 노트가 있고, 퀴즈 정답·해설을 다시 계산해 확인했으며, 학생 이름·사진과 교과서 본문·삽화가 들어가지 않았는가
- [ ] pptx와 `deck-browser.html`을 함께 전달하고, PowerPoint 버전별 차이·등록·인터넷 조건과 초안임을 알렸는가
