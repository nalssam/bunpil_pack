# 덱 HTML 작성 규칙

살아있는 PPT의 덱은 **HTML 한 파일**이다. `assets/deck-template.html`을 복사해 내용만 바꾸는 것이 가장 안전하다. 처음부터 쓰거나 다른 HTML을 가져올 때는 아래를 지킨다.

## 1. 뼈대

| 규칙 | 이유 |
|---|---|
| 슬라이드 하나 = `<section class="slide">` 하나 | 변환기가 이 수만큼 PowerPoint 슬라이드를 만든다 |
| 페이지가 열릴 때 `window.__LIVE_SLIDE__`(1부터)를 읽어 **그 슬라이드만** 보여 준다 | PowerPoint의 슬라이드마다 같은 HTML이 따로 실행된다 |
| 화면은 1920×1080 기준으로 그리고 창 크기에 맞춰 통째로 확대·축소한다 | 편집 화면(작게)과 슬라이드 쇼(전체 화면)에서 같은 모양 |
| 스타일·스크립트·그림을 한 파일에 담는다 | 파일 하나가 pptx 안에 저장된다 |

시작 틀 맨 아래의 "공통 스크립트"가 위 세 가지를 처리한다. 지우지 않는다. 4:3 화면이면 기준을 1440×1080으로 바꾸고 변환할 때 `--size 1440x1080`을 준다.

## 2. PowerPoint와 주고받기

추가 기능이 덱 안에 `window.liveSlide`를 넣어 준다(브라우저에서 그냥 열면 없다).

```js
if (window.liveSlide) {
  liveSlide.index;        // 지금 슬라이드 번호
  liveSlide.next();       // 다음 슬라이드로   (prev, first, last, goTo(3) 도 있다)
  liveSlide.keys = false; // ← → PageUp PageDown 을 덱이 직접 쓰고 싶을 때
}
```

- 화면을 한 번 누르면 키보드가 HTML 쪽으로 넘어온다. 그래도 발표가 끊기지 않게 **← → PageUp PageDown**(리모컨 포함)은 PowerPoint로 전달된다. 입력칸·슬라이더·선택 상자에 초점이 있을 때와 덱이 `preventDefault()`한 키는 전달하지 않는다.
- 덱에 "다음" 단추를 두려면 `onclick="window.liveSlide && liveSlide.next()"`.

## 3. 활동 부품 (시작 틀에 들어 있는 것)

| 부품 | 쓰임 | 고칠 곳 |
|---|---|---|
| 뒤집는 카드 `.flip` | 생각해 보고 눌러 확인 | `.q`(질문) `.a`(답) |
| 슬라이더 조작 | 값을 바꾸면 그림이 달라지는 탐구 | `bar()` 함수 |
| 4지선다 퀴즈 | 확인 문제, 해설 | `QS` 배열(`q` 문제, `o` 보기, `a` 정답 순서, `why` 해설) |
| 타이머 | 모둠 활동 시간 | `data-t`(초) |
| 번호 뽑기 | 발표 순서 | `nmax`(인원) — 이름이 아니라 번호만 |
| 정리 체크 | 배운 것 함께 확인 | `.check` 문장 |

새 부품을 만들 때: 한 장에 활동 하나, 단추는 크게(전자칠판에서 손가락으로 누른다), 글자는 1920 기준 30px 이상, 색만으로 정답·오답을 구분하지 않는다(기호·글자 함께).

## 4. 안 되는 것

| 안 되는 것 | 대신 |
|---|---|
| 슬라이드 사이에 값 넘기기(점수 누적 등) | 한 활동을 한 장 안에서 끝낸다. 슬라이드를 떠났다 돌아오면 처음 상태가 된다 |
| `localStorage`·쿠키 | 격리된 틀에서 실행되어 쓸 수 없다. 변수에만 둔다 |
| `alert` `confirm` `prompt` | 화면 안에 글자로 보여 준다 |
| 다른 사이트로 이동, 새 창 | 필요한 내용은 덱 안에 넣는다 |
| 마이크·카메라·위치 | 지원하지 않는다 |
| 큰 영상·소리 파일 넣기 | HTML이 약 1.9MB를 넘으면 변환을 멈춘다. 영상은 PowerPoint의 다른 슬라이드에 넣는다 |
| 학생 이름·사진 | 번호·가명·도형으로 대신한다 |

## 5. 그림과 글꼴

- 그림·CSS·JS를 따로 둔 파일(`<img src="img/a.png">` 등)은 변환기가 HTML 안으로 넣어 준다. 슬라이드 수만큼 한 벌씩 저장되므로 그림은 작게(한 장 200KB 이하 권장) 쓴다. 도형·SVG가 가장 가볍다.
- 글꼴은 컴퓨터에 있는 것을 쓴다(`"Pretendard","Malgun Gothic","Apple SD Gothic Neo",sans-serif`). 인터넷 글꼴·CDN은 학교망에서 막히거나 느릴 수 있어 쓰지 않는다. 변환기가 "인터넷에서 불러오는 주소"를 알려 주면 없앤다.
- 저작권 있는 캐릭터·교과서 삽화·출처를 모르는 그림은 넣지 않는다.

## 6. 발표자 노트

`<section class="slide" data-notes="교사 발문, 예상 반응, 시간">` 또는 슬라이드 안의 `<aside class="notes">…</aside>`(화면에는 `display:none`으로 숨긴다)가 PowerPoint 메모란으로 들어간다. 형성평가 정답처럼 학생에게 보이면 안 되는 것은 노트에만 쓴다.

## 7. 미리보기 그림

변환기는 슬라이드마다 첫 화면을 그림으로 찍어 넣는다. 추가 기능이 없는 컴퓨터, 휴대폰, 인쇄·PDF에서는 이 그림이 보인다. 그래서 **누르기 전 첫 화면만 봐도 무엇을 하는 장인지 알 수 있게** 만든다(빈 화면에서 시작하지 않는다).
