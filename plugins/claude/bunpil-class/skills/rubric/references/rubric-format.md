# 루브릭 표 형식

## 1. 4수준 표 (기본)

| 평가요소 | 성취기준 연결 | 매우 잘함 (4) | 잘함 (3) | 보통 (2) | 노력 필요 (1) |
|---|---|---|---|---|---|
| {{요소1}} | {{코드 또는 내용 / 확인 필요}} | {{관찰 가능한 행동}} | {{…}} | {{…}} | {{…}} |
| {{요소2}} | … | … | … | … | … |

## 2. 3수준 표 (상·중·하)

| 평가요소 | 성취기준 연결 | 상 | 중 | 하 |
|---|---|---|---|---|

## 3. 선택 열
- 비중(%): 교사가 정한다. 제안 시 "예시"로 표시.
- 평가 방법: 관찰 / 결과물 / 발표 / 동료평가 / 자기평가
- 피드백 문장 틀: "다음에는 ~을 해 보자."

## 4. 수준 사이 차이를 만드는 방법

| 차이 기준 | 4 → 1 로 내려갈 때 |
|---|---|
| 개수 | 근거 3개 이상 → 2개 → 1개 → 없음 |
| 정확성 | 오류 없음 → 사소한 오류 → 주요 오류 1~2개 → 개념 혼동 |
| 깊이 | 이유와 사례로 설명 → 이유만 → 나열 → 문장 단위로만 |
| 독립성 | 스스로 → 질문 한두 번으로 → 안내 받아 → 모델을 따라 |
| 완성도 | 모든 부분 완성 → 한 부분 미완 → 절반 → 시작만 |

## 5. 쓰지 말아야 할 표현

| 피할 표현 | 바꿔 쓰기 |
|---|---|
| 잘 썼다 / 훌륭하다 | 구체 행동(주장을 한 문장으로 쓰고 이유를 2개 들었다) |
| 성의가 있다 / 노력한다 | 확인 가능한 산출물(초고와 고친 글이 모두 있다) |
| 창의적이다 | 기준을 쪼갬(제시된 예와 다른 사례를 1개 이상 들었다) |
| 적극적으로 참여한다 | 관찰 행동(모둠 활동에서 의견을 2회 이상 말했다) |

## 6. 인쇄
- A4 가로, 글자 10pt, 표 선 1px. 수준 열 너비는 같게.
- 맨 위에 "초안 · 교사 확인 후 사용"을 적는다.
