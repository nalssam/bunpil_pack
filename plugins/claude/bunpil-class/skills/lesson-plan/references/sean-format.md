# 세안(세부 지도안) 형식

공개수업·연구수업·교육실습용이다. 약안 내용에 아래 항목이 더해진다. 학교·지역 서식이 있으면 그 목차를 우선한다.

## 목차

1. **단원 개관**
   - 단원의 성격(교육과정상 위치, 이 단원에서 길러야 할 역량) 3~5문장
   - 단원 학습 목표
2. **성취기준·단원 지도 계획**
   - 성취기준(코드는 확실할 때만)
   - 차시별 계획표: 차시 / 학습 주제 / 주요 활동 / 평가 / (본 차시 표시)
3. **학습자 분석**
   - 선수 지식, 학습 양식, 흥미 수준을 **학급 전체 수준**으로 기술한다.
   - 개별 학생 서술 금지. 지원이 필요한 학생이 있으면 "학습 지원 필요 학생 A" 형태로 일반화하고 진단명·가정 사정은 쓰지 않는다.
4. **수업 설계 방향**
   - 수업 모형 선택 이유, 핵심 발문 전략, 에듀테크 활용 계획(교사용 도구 중심)
5. **본시 교수·학습 과정안**
   - 약안 표(`yakan-format.md`)와 같은 열 구성에 **학습 형태(전체·모둠·개별)** 열과 **예상 학생 반응·교사 대응** 열을 더한다.
   - 활동별 발문 목록: 핵심 발문 / 보충 발문 / 심화 발문
6. **판서 계획**: 칠판을 3구역으로 나눠 무엇을 어디에 쓰는지 간단한 표나 그림 설명
7. **평가 계획**
   - 평가 요소 × 평가 방법 × 시기
   - 평가 기준표(3~4수준): 루브릭 연결 시 `rubric` 스킬 활용
   - 피드백 방법(교사·동료·자기)
8. **부록**
   - 활동지(학습지는 `worksheet` 스킬), 자료 목록, 참고 문헌(교과서 쪽수, 출처)

## 분량 기준

- 세안 5~8쪽. 본시 과정안이 전체의 절반 이상.
- 표와 문단을 섞고, 같은 내용을 반복해 쓰지 않는다.

## 확인 메모

- 학교별 서식 차이가 크다. 서식 파일을 받으면 그 항목 순서로 맞춘다(원본은 수정하지 않고 복사해서 쓴다).
