# 수업 영상 만들기

교사가 수업과 행사에 쓸 짧은 영상(개념 설명, 수업 도입, 학교·학급 소개) 초안을 만든다. 영상은 코드로 그려 `.mp4`로 낸다. 사실과 수식은 AI가 틀릴 수 있으므로 **교사가 처음부터 끝까지 보고 확인**한 뒤에 쓴다.

## 시작하기 전에

1. 작업 폴더의 `CLAUDE.md` 또는 `AGENTS.md`를 읽는다. 학교급, 학년, 말투(해요체 등), 선호 색이 있으면 반영한다.
2. **빠진 것만** 묻는다: 용도, 학년·교과·단원(또는 행사 이름), 길이, 화면 비율(수업용 가로 1920×1080 / 릴스·쇼츠용 세로 1080×1920), 음성(목소리·없음), 쓸 로고·사진이 있는지.
3. 용도로 방법을 고른다.

| 용도 | 방법 | 기본 길이 |
|---|---|---|
| 개념 설명(분수, 광합성, 미분 등) | **A. Manim + 음성** | 60~120초 |
| 학교·학급·행사 소개, 도입 티저 | **B. Cinetic 스킬** (없거나 Windows면 C) | 15~30초 |
| 위 둘이 안 될 때 | **C. HTML 화면 + ffmpeg** | 15~60초 |

## 지켜야 할 원칙

- 학생 실명·학번·생년월일·주소·연락처·가족관계·사진 등 개인을 알아볼 수 있는 정보가 보이면 작업을 멈추고 '학생A'처럼 가명으로 바꾸자고 제안한다. 결과물에는 개인정보를 넣지 않는다.
- 결과물은 모두 **초안**이다. 학생에게 틀기 전, 학교 누리집에 올리기 전에 교사가 확인한다.
- 학생 얼굴·목소리·실명이 들어간 영상은 만들지 않는다. 필요하면 도형·일러스트·'학생A'로 바꾼다.
- 음성 합성(edge-tts)은 **대본 글을 인터넷의 음성 합성 서비스로 보내** 처리한다. 대본에 학생 정보나 공개하면 안 되는 내용을 넣지 않는다. 학교 공식 영상으로 배포하기 전에는 서비스 이용 약관을 확인하라고 알린다.
- 음악·글꼴·이미지는 직접 코드로 만든 것이거나 라이선스를 확인한 것만 쓴다. 출처를 알 수 없는 인터넷 이미지는 쓰지 않는다.
- prompt-motion.com의 영상과 프롬프트는 각 원작자의 것이다. **참고해서 우리 내용으로 새로 만들 뿐**, 원문 영상을 그대로 쓰거나 다시 올리지 않는다.
- 사실·수치·수식은 교사가 준 자료(교과서 쪽 등)에서 확인된 것만 쓴다. 확인 못 한 내용은 "확인 필요"로 표시한다.
- AI로 만든 영상을 학생·학부모에게 공개할 때는 설명란이나 마지막 화면에 밝히도록 권한다.
- 컴퓨터에 새로 설치해야 하면 **이름·크기·이유를 말하고 동의를 받는다.** 관리자 권한(sudo)이 필요한 명령은 직접 실행하지 않고 교사나 정보 담당 선생님께 안내한다.

## 준비 점검 (처음 한 번)

터미널에서 아래를 확인하고, 없는 것만 알린다. 이미 다 있으면 건너뛴다.

| 도구 | 확인 명령 | 필요한 곳 |
|---|---|---|
| ffmpeg 6 이상 | `ffmpeg -version` | A·B·C 모두 |
| Python 3.11 이상 | `python3 --version` (Windows `py --version`) | A·B |
| Node.js 22 이상 | `node --version` | B·C |
| 브라우저(Chromium) | `npx playwright install chromium` | B·C 화면 캡처 |

- macOS: `brew install ffmpeg node python@3.12` (Homebrew가 없으면 안내만)
- Windows: `winget install Gyan.FFmpeg` · `winget install OpenJS.NodeJS.LTS` · `winget install Python.Python.3.12` — 설치 뒤 새 터미널 창을 연다.
- Ubuntu·WSL2: `sudo apt install ffmpeg python3-venv` 는 교사가 직접 실행하도록 안내한다. 배포판의 ffmpeg가 6 미만이면 공식 정적 빌드를 쓰라고 알린다.
- **Cinetic은 bash 스크립트**라 macOS·Linux·WSL2에서만 된다. Windows 기본 터미널이면 A 또는 C로 안내한다.

## 방법 A. 설명 영상 (Manim + 음성)

1. **대본·스토리보드를 먼저** 표로 보여 준다: 장면 번호 · 화면에 나올 것 · 읽을 문장 · 예상 초. 문장은 학년 수준으로, 한 문장에 개념 하나, 질문으로 생각할 틈을 둔다. 교사가 고치면 반영하고, 승인 전에는 렌더하지 않는다.
2. **파이썬 환경** (한 번만): 작업 폴더 밖에 가상환경을 만든다.
   - macOS·Linux: `python3 -m venv ~/.venvs/classvideo && . ~/.venvs/classvideo/bin/activate && pip install manim edge-tts`
   - Windows: `py -m venv %USERPROFILE%\.venvs\classvideo` → `%USERPROFILE%\.venvs\classvideo\Scripts\activate` → `pip install manim edge-tts`
   - 설치가 막히면(특히 Linux에서 cairo·pango 오류) 오류를 그대로 보여 주고, macOS는 `brew install pango pkg-config`, Ubuntu는 `libcairo2-dev libpango1.0-dev pkg-config python3-dev` 설치를 교사(또는 정보 담당)에게 안내한다. 계속 안 되면 방법 C로 바꾼다.
3. **음성 만들기**: `edge-tts --list-voices`로 `ko-KR` 목소리를 확인해 고른다(예: `ko-KR-SunHiNeural` 여, `ko-KR-InJoonNeural` 남). 장면마다 `edge-tts --voice <목소리> --text "<읽을 문장>" --write-media outputs/영상/scene01.mp3 --write-subtitles outputs/영상/scene01.vtt`. 길이는 `ffprobe -v error -show_entries format=duration -of csv=p=0 scene01.mp3`로 잰다.
4. **Manim 장면 만들기**: 장면마다 `Scene` 클래스 하나. 한글은 `Tex`가 아니라 `Text`로 쓰고 글꼴을 지정한다(Windows `Malgun Gothic`, macOS `Apple SD Gothic Neo`, Linux `Noto Sans CJK KR`). 장면 길이는 음성 길이에 맞춰 `self.wait()` 값을 정한다. 글자는 크게(수업 교실 뒷자리에서 보이게), 한 화면에 개념 하나.
5. **시험 렌더** 먼저: `manim -ql scene.py Scene01`(저화질)로 한 장면을 만들어 교사에게 정지 화면을 보여 준다. 괜찮으면 `-qh`로 전체를 렌더한다.
6. **합치기**: 장면별로 `ffmpeg -i scene01.mp4 -i scene01.mp3 -c:v copy -c:a aac -shortest s01.mp4`, 이어 붙이기는 `ffmpeg -f concat -safe 0 -i list.txt -c copy 영상.mp4`. 자막(`.vtt`)은 파일로 함께 준다.

## 방법 B. 소개·도입 영상 (Cinetic 스킬)

1. Cinetic 스킬이 있는지 `~/.claude/skills/cinetic`, `~/.agents/skills/cinetic`을 확인한다. 없으면 분필팩 사이트의 "설치 문장 만들기"에서 creator 묶음을 더한 설치 문장을 채팅창에 다시 붙여넣으라고 안내한다(터미널은 `--profile creator`. macOS·Linux·WSL2에서만 된다).
2. 있으면 **그 스킬의 절차를 그대로 따른다.** 요청은 짧게 쓴다. 예: "[학교·행사 한 줄 소개]의 20초 소개 영상을 소리까지 넣어서 만들어 줘. 브랜드(색·글꼴)는 학교 기준을 따라 줘."
3. 처음에는 그 스킬의 안내대로 **시험 렌더** 한 번으로 컴퓨터가 렌더 가능한지 확인한다. 막히면 오류를 그대로 보여 주고 방법 C로 바꾼다.
4. 만들기 전에 컨셉·장면 구성안을 교사에게 보여 주고 승인받는다.

## 방법 C. HTML 화면 + ffmpeg

컨셉 하나, 장면 3~6개. 장면마다 HTML·CSS 애니메이션 페이지를 만들고 Playwright로 프레임을 캡처해 `ffmpeg`로 `.mp4`로 만든다. 음성이 필요하면 방법 A 3번의 edge-tts를 쓴다. 장면 이어 붙이기·길이 맞추기는 A 6번과 같다.

## 참고 영상 찾기 (Prompt Motion)

비슷한 영상을 보고 시작하고 싶다는 교사에게 안내한다.

1. 브라우저에서 prompt-motion.com을 연다(로그인 없음). 분야 버튼(제품 화면·움직이는 글자·도표·차트 등)으로 거르고, 마음에 드는 영상을 눌러 프롬프트 원문의 **Copy**를 누른다.
2. 복사한 프롬프트를 교사가 붙여 주면, **우리 학교·수업 내용으로 바꿔서** 만든다. 앞에 "아래 프롬프트를 참고해 새로 만들어 줘. 내용은 [우리 주제]로 바꿔 줘."를 붙이는 식이다. 사진·음악을 먼저 묻는 프롬프트는 재료를 받은 뒤에 진행한다.
3. 색·길이·박자를 직접 정하고 싶으면 사이트의 Customize 화면에서 칸을 채워 복사하라고 안내한다.

## 절차

1. 용도·학년·길이를 정하고 방법을 고른다.
2. 준비 점검을 하고 부족한 것을 알린다(설치는 동의 후).
3. 스토리보드(또는 컨셉)를 보여 주고 승인받는다.
4. 짧은 시험 렌더로 정지 화면을 확인받는다.
5. 전체를 렌더한다. 오래 걸리면 진행 상황을 알린다.
6. 점검 후 `outputs/영상/영상_<교과>_<주제>.mp4`로 저장한다.
7. **보고**: 저장 위치, 길이, 해상도, 쓴 도구와 목소리, 교사가 확인할 곳(수식·사실·발음), 자막 파일 위치를 알린다.

## 점검

- [ ] 학생 이름·얼굴·목소리·사진이 영상과 대본에 없는가
- [ ] 사실·수식·용어가 교사가 준 자료와 맞고, 확인 못 한 것은 "확인 필요"로 표시했는가
- [ ] 스토리보드 승인과 시험 렌더 확인을 거쳤는가
- [ ] 글자가 교실 뒷자리에서 보일 만큼 크고, 한 화면에 개념이 하나인가
- [ ] 음악·글꼴·이미지의 출처와 이용 조건이 확인된 것뿐인가
- [ ] 음성은 읽는 속도가 학년에 맞고, 자막 파일을 함께 줬는가
- [ ] 초안임과 AI 제작 표시 권고를 알렸는가
