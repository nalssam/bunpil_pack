# 분필 설정 마법사

선생님 한 분 한 분에게 맞는 AI 작업 환경(하네스)을 만든다. 결과는 AI가 매번 먼저 읽는 **지침 파일**과, 선생님이 앞으로 직접 고쳐 나갈 **my-harness 폴더**다. 10분 안에 끝내는 것이 목표다.

개인정보 원칙: 학생 실명·학번·생년월일·주소·연락처·가족관계·사진 등 개인을 알아볼 수 있는 정보가 보이면 작업을 멈추고 '학생A'처럼 가명으로 바꾸자고 제안한다. 결과물에는 개인정보를 넣지 않는다.

## 시작 전 확인

1. 작업 폴더에 `CLAUDE.md` 또는 `AGENTS.md`가 이미 있으면 내용을 요약해 보여 주고 묻는다: "기존 지침을 고칠까요, 새로 만들까요?" 덮어쓰기 전에는 반드시 `CLAUDE.backup.md`처럼 사본을 남긴다.
2. 파일을 쓸 수 없는 환경(웹 채팅 등)이면 마지막에 지침 전문을 보여 주고 붙여 넣는 곳을 안내한다(아래 "채팅 환경" 참고).

## 인터뷰 (한 번에 한 질문)

시작 인사는 한 줄로 한다: "선생님께 맞는 AI 환경을 만들기 위해 10가지만 여쭤볼게요. 모르시면 '건너뛰기'라고 하셔도 됩니다."

질문마다 선택지 예시를 붙여 쉽게 답하게 한다. 답을 받으면 다음 질문으로 바로 넘어가고, 답을 되풀이해 확인하지 않는다.

| 번호 | 질문 | 선택지 예시 |
|---|---|---|
| 1 | 학교급 | 초등 / 중학교 / 고등학교 / 특수 / 기타 |
| 2 | 학년과 교과, 담임 여부 | "4학년 담임", "중2 과학 교과", "고1·2 영어" |
| 3 | 맡은 업무(부서) | 교무, 연구, 생활, 정보, 창의융합진로, 방과후, 없음 |
| 4 | 가장 자주 만드는 문서 3가지 | 학습지, 지도안, 가정통신문, 공문 기안, 회의록, 평가 계획 |
| 5 | 결과물 문체 | 이다체(보고서형) / 해요체(안내문형) / 개조식(~함·~임) |
| 6 | 학교 서식 특이사항 | "학습지는 2단", "가정통신문 머리말에 학교 로고 자리" |
| 7 | 주로 쓰는 도구 | 한글(HWP), 구글 문서·시트, 캔바, 패들렛, 노션 |
| 8 | AI에게 맡기지 않을 일 | 예: 생활기록부 문구, 학부모 민원 답장 최종본 |
| 9 | 개인정보 원칙 동의 | "학생 실명 대신 가명을 쓰고, 결과물은 제가 최종 확인합니다"에 동의 여부 |
| 10 | 내 하네스 이름 | 예: "햇살반 AI 조수", "과학실 하네스" |

- 2번에 학교명을 붙여 답하면 학교명은 지침에 넣지 않는다고 짧게 알린다(공유할 때 안전하도록).
- 9번에 동의하지 않으면 왜 필요한지 2문장으로 설명하고, 그래도 원하지 않으면 개인정보 원칙 절은 그대로 두되 "동의 보류"로 표시한다. 원칙 자체를 빼지 않는다.
- 인터뷰 중 학생 실명이나 연락처가 나오면 즉시 멈추고 가명으로 다시 말해 달라고 요청한다. 그 내용은 어떤 파일에도 쓰지 않는다.

## 파일 만들기

`assets/harness-template.md`를 읽어 답을 채운다. 건너뛴 항목은 줄을 지우지 말고 "(아직 정하지 않음 — 나중에 harness-fix로 추가)"로 둔다.

1. `CLAUDE.md`와 `AGENTS.md`를 **같은 내용**으로 만든다. 한쪽만 있으면 다른 AI 도구에서 지침을 못 읽는다.
2. `my-harness/README.md` — "이 폴더는 선생님의 하네스입니다. 분필팩이 업데이트되어도 이 폴더는 바뀌지 않습니다."와 폴더 설명.
3. `my-harness/rules.md` — 지금까지의 규칙 목록(6번·8번 답에서 나온 것)과 "규칙 추가 기록" 표.
4. `my-harness/skills/` 빈 폴더(나중에 skill-maker가 쓴다).
5. `logs/failure-log.md` — 실패 기록 서식(날짜·문제·원인·수정한 규칙·재시험 결과).

## 마무리 안내

만든 파일 목록을 3줄 이내로 보여 주고, 4번 답에 맞춘 **첫 과제 3개**를 바로 실행할 수 있는 문장으로 추천한다. 예:

- "다음 주 4학년 과학 '물의 상태 변화' 학습지를 기본·심화 2수준으로 만들어줘"
- "input_docs 폴더에 넣은 공문 처리해줘"
- "현장체험학습 가정통신문 초안 써줘"

마지막 한 줄: "결과가 마음에 안 들면 '앞으로는 ~해줘'라고 말씀해 주세요. 그 말이 규칙이 되어 다음부터 반영됩니다. 이것이 하네스 엔지니어링입니다."

## 채팅 환경(파일을 쓸 수 없을 때)

- 지침 전문을 코드 블록 하나로 보여 준다.
- 붙여 넣을 곳: Claude 앱은 프로젝트 → 지침(Instructions), ChatGPT는 프로젝트 지침 또는 맞춤 설정. 파일로 저장하려면 `CLAUDE.md`·`AGENTS.md`라는 이름으로 작업 폴더에 둔다고 알린다.

## 점검

- [ ] CLAUDE.md와 AGENTS.md 내용이 같은가
- [ ] 학생 실명·연락처·학교명이 어떤 파일에도 없는가
- [ ] 개인정보 원칙 절이 지침에 들어 있는가
- [ ] 기존 지침을 덮어쓰기 전에 사본을 남겼는가
- [ ] 첫 과제 3개가 선생님 답(학년·교과·문서)에 맞는가
