# 연결 문제 해결

증상을 하나씩 확인하고, 해당하는 것부터 한 단계씩 안내한다. 한 번에 여러 가지를 시키지 않는다. 비밀번호나 인증 코드를 채팅에 보내라고 하지 않는다.

## 1. 연결이 안 됨 ("인증 필요"가 계속 나오거나, 목록에 서버가 없음)

1. 분필 커넥터 팩(`bunpil-connect`)이 설치되어 있고 켜져 있는지 확인한다.
2. 설치 직후라면 프로그램을 새로 시작한다(앱은 완전히 종료 후 다시 열기, Claude Code는 새 세션, Codex는 새 터미널).
3. 환경별 확인 위치
   - Claude Code: `/mcp` 에서 `notion`, `padlet`, `canva`가 보이는가. 안 보이면 플러그인 설치·활성 여부를 다시 본다.
   - Claude 앱 Code 탭: 입력창 옆 + → Connectors에서 해당 서비스가 보이는가.
   - Claude 앱 Chat·Cowork: 사용자 지정 → 커넥터에서 해당 서비스가 보이는가. 조직(학교·기관) 계정이라면 관리자가 커넥터를 막아 두었을 수 있다.
   - Codex: `codex mcp list` 로 서버가 보이는가. 안 보이면 플러그인을 다시 설치한다.
4. 로그인은 되었는데 "권한 없음" 또는 빈 결과가 나오면, 서비스 쪽에서 AI에게 허용한 페이지·보드 범위를 확인한다. 노션은 연결 시 고른 페이지만 보인다. 다시 연결하며 범위를 넓힌다. (학생 정보가 있는 곳은 넓히지 않는다.)
5. 로그인한 계정이 맞는지 확인한다. 개인 계정과 학교 계정이 달라 내용이 비어 보이는 경우가 많다.
6. 한동안 안 쓰면 로그인이 풀린다. 다시 로그인(재인증)한다.
7. 그래도 안 되면 서비스를 끊었다가 다시 연결한다(Claude Code `/mcp`에서 해당 서버 선택 후 인증을 다시 진행, Codex는 `codex mcp login <이름>`을 다시 실행).
8. 캔바 연결 주소는 부분 확인 상태이다. 다른 서비스는 되는데 캔바만 안 되면 그대로 몽당분필에 알리고(증상과 환경만, 개인정보 없이) [확인 필요]로 표시한다.

## 2. 로그인 창이 안 뜸

1. 브라우저 창이 **다른 창 뒤에 숨어** 있지 않은지 확인한다. 작업 표시줄을 본다.
2. 팝업 차단이 켜져 있으면 허용한다. 앱 안에서 열리는 창이면 앱 쪽 알림을 확인한다.
3. 기본 브라우저가 지정되어 있어야 한다. 기본 브라우저를 한 번 설정한다.
4. 터미널(Claude Code, Codex)에서는 열리지 않을 때 **주소가 화면에 출력**되는 경우가 있다. 그 주소를 교사가 직접 복사해 브라우저에 붙여 넣어 로그인한다. 로그인 후 돌아와 완료되었는지 `/mcp` 또는 `codex mcp list`로 본다.
5. 원격 접속(원격 데스크톱, 학교 공용 PC, 가상 환경)에서는 브라우저가 다른 컴퓨터에서 열릴 수 있다. 가능하면 교사 본인 컴퓨터에서 연결한다.
6. 학교 공용 PC에서는 로그인 정보가 남을 수 있으니, 끝난 뒤 서비스 로그아웃과 연결 해제를 하고 브라우저에 비밀번호를 저장하지 않는다.
7. 로그인 창에서 오류가 나면 오류 문구를 그대로 알려 달라고 하되 비밀번호·코드는 가리게 한다.

## 3. 학교 방화벽·네트워크

연결 주소는 `mcp.notion.com`, `mcp.padlet.com`, `mcp.canva.com` 이다(로그인은 각 서비스의 도메인에서 진행). 학교 네트워크가 이를 막으면 연결되지 않는다.

1. 같은 컴퓨터를 집이나 모바일 핫스팟 같은 다른 네트워크에 연결해 되는지 본다. 되면 학교 네트워크 차단이 원인이다.
2. 학교 정보 담당 선생님 또는 교육청 정보보안 담당에게 허용 가능 여부를 문의하도록 안내한다. 문의 글 초안은 만들어 줄 수 있다. (연결 주소 3개와 사용 목적만 쓴다.)
3. 학교 보안 정책으로 허용되지 않으면 **우회하지 않는다**. VPN이나 프록시 우회, 보안 설정 해제를 권하지 않는다. 대신 집이나 허용된 환경에서 쓰도록 안내한다.
4. 기관 계정에서 외부 앱 연결이 제한된 경우도 같다. 관리자 정책을 따른다.
5. 회사·학교 프록시를 쓰는 환경에서 인증서 오류가 나면 정보 담당자에게 문의한다. 인증서 검증을 끄라고 하지 않는다.

## 4. 연결은 됐는데 AI가 서비스를 안 씀

1. 요청에 서비스 이름을 분명히 넣는다. ("노션의 '수업일지' 페이지에…", "패들렛 보드 '1모둠 토론'의 게시물을…")
2. 서비스가 두 개 이상 겹쳐 있으면(공식 플러그인과 분필 커넥터) 하나만 켜 둔다.
3. 새 대화(세션)를 시작한다.

## 5. 연결을 끊고 싶을 때

- Claude Code: `/mcp` 에서 해당 서버의 인증 해제, 또는 플러그인 비활성화
- Claude 앱 Code 탭: 설정 → Connectors(또는 입력창 옆 + → Connectors → Manage connectors)에서 연결 해제
- Claude 앱 Chat·Cowork: 사용자 지정 → 커넥터에서 연결 해제
- Codex: 서버 로그아웃 또는 플러그인 제거
- 서비스 쪽(노션 설정의 연결, 패들렛·캔바의 앱 연결 관리)에서도 허용을 취소할 수 있다.
- 학교 공용 PC나 업무가 끝난 뒤에는 연결을 끊는 것이 안전하다.

## 안내할 때 지킬 점

- 교사가 직접 로그인하게 한다. 비밀번호·인증 코드를 요구하거나 대신 입력하지 않는다.
- 해결되지 않으면 몽당분필에 문의할 때 증상, 환경(어떤 앱·운영체제), 오류 문구만 적고 학생 정보나 계정 정보는 넣지 않게 한다.
