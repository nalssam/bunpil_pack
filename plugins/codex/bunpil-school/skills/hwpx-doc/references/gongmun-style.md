# 공문서 작성 요지

기준: 「행정업무의 운영 및 혁신에 관한 규정」 제7조(문서 작성의 방법)와 같은 규정 시행규칙, 행정업무운영편람의 서식 관례. 아래는 확신하는 규칙만 적었다. 2025년 개정 내용은 개정 전문을 대조하지 못했으므로 '확인 필요'로 표시했고, 학교·교육청 안내가 이 문서와 다르면 학교·교육청 안내를 따른다.

## 항목 기호

| 단계 | 기호 | 예 |
|---|---|---|
| 1 | 1., 2., 3. | `1. 관련:` |
| 2 | 가., 나., 다. | `가. 일시:` |
| 3 | 1), 2), 3) | `1) 신청 방법` |
| 4 | 가), 나), 다) | `가) 개인별 신청` |
| 5 | (1), (2), (3) | |
| 6 | (가), (나), (다) | |
| 7 | ①, ②, ③ | |
| 8 | ㉮, ㉯, ㉰ | |

- 항목이 하나뿐이면 항목 기호를 붙이지 않는다.
- 첫째 항목은 왼쪽 처음부터 쓰고, 둘째 항목부터는 앞 단계보다 한 글자(2타) 오른쪽에서 시작한다.
- 항목 기호와 내용 사이는 한 칸 띄운다.
- 항목이 한 줄을 넘으면 둘째 줄은 윗줄 내용의 첫 글자에 맞춘다.

## 날짜와 시간

- 날짜: 연·월·일 글자를 빼고 그 자리에 온점. **2026. 10. 13.** (온점 뒤 한 칸, 마지막 온점 포함)
- 요일은 괄호로: 2026. 10. 13.(화) — 온점 뒤 요일 괄호를 붙여 쓰는 관례. 요일 괄호 안 온점 여부는 확인 필요.
- 시간: 24시각제, 시·분 글자를 빼고 쌍점. **14:30**, 09:30
- 기간: 물결표로 잇는다. 2026. 10. 19.~10. 30. (물결표 앞뒤 띄어쓰기는 문서마다 다름 — 확인 필요)

## 금액

- 아라비아 숫자로 쓰고 괄호 안에 한글을 병기한다. **금15,000원(금일만오천원)**
- 숫자 앞에 '금'을 붙이고 '원'으로 마친다.

## 붙임과 끝 표시

- 붙임이 있으면 본문 마지막 줄 다음에 `붙임`을 쓰고 한 칸 띄운 뒤 파일 이름과 수량을 쓴다. 마지막에 두 칸 띄우고 `끝.`
  ```
  붙임 1. ○○ 계획 1부.
        2. ○○ 서식 1부.  끝.
  ```
- 붙임이 하나면 `붙임 ○○ 계획 1부.  끝.`
- 붙임이 둘 이상이면 번호를 쓰고, 둘째 줄부터 번호를 첫째 붙임 이름의 첫 글자에 맞춘다.
- 붙임이 없으면 본문 마지막 글자 뒤에 한 칸 띄우고 `끝.`
- 표나 서식이 본문 마지막이면 표 아래 왼쪽 첫 칸에 `끝.`을 쓰는 관례가 있다 — 확인 필요.

## 문장과 용어

- 한글 맞춤법을 따르고, 쉬운 우리말을 쓴다. 한자나 외국어는 필요할 때만 괄호 안에 병기한다.
- 숫자는 아라비아 숫자를 쓴다. 용지는 A4가 기본이다.
- 쌍점(:)은 앞에 붙이고 뒤는 한 칸 띄운다. `일시: 2026. 10. 13.` (시각 14:30처럼 숫자 사이는 붙여 쓴다.)
- 두괄식으로, 문장은 짧게. 상대를 낮추거나 고압적인 표현을 피한다.

## 기안문 구성 (참고)

- 두문: 행정기관명, 수신, (경유), 제목
- 본문: 1. 관련 → 2. 요청·안내 내용 → 항목 → 붙임·끝 (내부 기안문 본문 초안은 SKILL.md의 '기안문 본문 초안' 순서를 따른다)
- 결문: 발신 명의, 기안자·검토자·결재권자, 협조자, 시행 번호(일자), 접수, 우편번호·주소·연락처·공개 구분

## 확인 필요 목록

- 2025년 개정 사항 전반(개정 전문과 대조하지 못했다. 교육청·학교 안내문을 확인한다)
- 요일 괄호 안 온점 표기, 기간 물결표 띄어쓰기
- 표가 마지막일 때 `끝.` 위치
- 한글 프로그램의 서식 단위(들여쓰기 칸 수)는 학교 서식에 맞춘다
