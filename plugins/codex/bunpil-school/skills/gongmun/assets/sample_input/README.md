# 연습용 가상 공문

`예시공문1_교원연수안내.md`, `예시공문2_자료제출요청.md`는 연습용으로 만든 가짜 문서다. 기관·인물·번호는 모두 가상이다.

사용법: 작업 폴더의 `input_docs/`에 두 파일을 복사한 뒤 "input_docs 폴더 공문 처리해줘"라고 요청한다.

살펴볼 점
- 예시공문2에는 마감일이 없다. 결과에 '확인 필요'로 표시되는지 본다.
- 두 공문 모두 담당 교사의 이름이 없다. 예시공문2에는 "학교별 안전교육 담당 교사"라는 역할만 적혀 있다. 이 역할은 그대로 쓰되 사람 이름은 지정하지 않고, 개인 담당자는 '담당자 확인 필요'로 나오는지 본다.
