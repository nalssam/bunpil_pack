# 가정통신문

학교가 학부모에게 보내는 안내문 초안을 만든다. 발송과 학교장 결재는 교사·학교가 한다.

## 시작 전

- 작업 폴더의 `CLAUDE.md` 또는 `AGENTS.md`를 읽어 학교명·학교급·문체(해요체/합쇼체)를 반영한다. 없으면 학교명과 문체만 짧게 묻는다.
- 학교 기존 가정통신문 서식이 폴더에 있으면 그것을 따른다. 없으면 `assets/newsletter_template.html`을 쓴다.

## 개인정보 원칙

학생 실명·학번·생년월일·주소·연락처·가족관계·사진 등 개인을 알아볼 수 있는 정보가 보이면 작업을 멈추고 '학생A'처럼 가명으로 바꾸자고 제안한다. 결과물에는 개인정보를 넣지 않는다.

- 전체 학부모에게 보내는 글에 특정 학생의 사례·잘못·성적을 쓰지 않는다. 사례가 필요하면 일반화해 쓰자고 제안한다.
- 학교 대표 전화·행정실 번호 같은 공개 연락처만 적는다. 교사 개인 휴대전화는 넣지 않는다.

## 초안 규칙과 원본 보호

- 결과는 초안이다. 첫머리 주석과 화면 미리보기 문구(`.no-print`)로만 '초안'을 표시하고, 인쇄·PDF에는 'AI가 만든 초안' 문구가 찍히지 않게 한다(학교장 명의 공식 통신문이다). 학교장 명의·직인·발송은 학교가 한다.
- 원본(기존 서식·이전 통신문)은 고치지 않고 `outputs/`에 새 파일로 저장한다. 채팅 전용 환경이면 대화에 제시한다.

## 입력

| 필요 | 비고 |
|---|---|
| 안내 주제 | 현장체험학습, 학부모 총회, 방학 생활 등 |
| 일시·장소·대상·준비물·비용 | 원문 근거가 있는 것만 쓴다 |
| 회신 필요 여부와 기한 | 없으면 회신서를 넣지 않는다 |
| 발송일, 학교장 이름 | 모르면 '○○○'로 비워 둔다 |

## 구성 (순서 고정)

1. **제목**: 행사·내용이 드러나게. 예) 2026학년도 ○학년 현장체험학습 안내
2. **인사**: 계절·학교 상황을 담은 2~3문장. 과장하지 않는다.
3. **본문**: 목적 → 안내 사항 → 학부모께 부탁드리는 일. 문단은 짧게, 핵심은 굵게.
4. **일정표**: 표(일시·장소·준비물 등). 날짜는 "2026. 10. 13.(화)" 형식, 시간은 24시간제 "09:30".
5. **회신서(선택)**: 절취선(점선) 아래에 참가 동의·희망 여부 체크, 학년 반 번호, 학생 이름 칸, 보호자 서명 칸. 칸은 비워 둔다.
6. **날짜와 학교장 명의 자리**: "2026. 10. 13." / "○○초등학교장" (직인 자리는 비워 둔다).

## 쉬운 말 버전과 다문화 가정용 요약 (선택)

- **쉬운 말 버전**: 한자어·행정 용어를 풀어 쓰고 한 문장을 짧게 한다. 핵심(언제·어디서·무엇을·준비물·회신 기한)을 맨 위에 박스로 둔다.
- **쉬운 한국어 요약**: 다문화 가정 학부모를 위한 5줄 안팎 요약. 쉬운 단어, 짧은 문장, 날짜와 숫자 중심, 한자어·줄임말·관용구 줄이기.
- 번역본은 AI가 만든 초안임을 화면 미리보기용(`.no-print`) 문구로 표시하고, 인쇄본에는 "궁금한 점은 담임 선생님께 물어보세요"처럼 학부모용 안내만 둔다. 중요한 안내는 담임이나 통역 지원을 통해 확인하도록 교사에게 알리고, 번역 언어 요청 시 만들되 "확인 필요"를 표시한다.
- 자세한 쓰기 요령은 `references/easy-korean.md`.

## 파일 만들기

- 기본: `assets/newsletter_template.html`의 `{{...}}` 자리를 채워 `outputs/가정통신문_<주제>_초안.html`로 저장한다. A4 인쇄 CSS가 들어 있다.
- 가능하면 PDF 또는 DOCX로 변환한다. 변환이 안 되면 HTML을 브라우저에서 인쇄(PDF로 저장)하도록 안내한다.
- 한글(HWPX) 파일이 필요하면 `hwpx-doc` 스킬을 참고한다.
- 회신서를 쓰지 않으면 템플릿의 회신서 구역(`<!-- REPLY-START -->`~`<!-- REPLY-END -->`)을 지운다.

## 날짜·정보가 미정일 때

날짜·장소·비용이 정해지지 않았으면 만들어 넣지 않고 "미정(확정 시 안내)" 또는 "확인 필요"로 둔다. 확정 후 갱신 안내문 초안이 필요한지 묻는다.

## 점검

- [ ] 제목·인사·본문·일정표·(회신서)·학교장 명의 자리가 모두 있는가
- [ ] 날짜·장소·비용·회신 기한이 사용자가 준 정보와 일치하고, 없는 정보는 '확인 필요'로 두었는가
- [ ] 특정 학생의 이름·사례가 없는가
- [ ] 회신서가 있다면 절취선과 기한, 빈칸이 맞는가
- [ ] 쉬운 말/요약 버전을 요청받았다면 만들었고 핵심 정보가 빠지지 않았는가
- [ ] '초안'이 화면 미리보기·첫머리 주석에만 있고 인쇄·PDF에는 찍히지 않는가, 분량이 A4 한 장(회신서 포함 최대 두 장)에 들어가는가
