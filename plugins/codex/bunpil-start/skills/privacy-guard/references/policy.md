# 분필팩 개인정보 정책 (교사용 요약)

## 사용 범위 선언
분필팩은 교사가 **수업 준비와 행정 업무**에 쓰는 도구다. 학생 개인정보를 처리하지 않는 것을 전제로 설계했고, 학생이 직접 사용하는 도구가 아니다.

참고: 2026학년도부터 학교가 학습지원 소프트웨어를 교육자료로 선정할 때는 필수 기준과 학교운영위원회 심의를 거친다. 교육부 안내는 "교사가 수업 준비나 행정 업무를 위해 학생 개인정보 처리 없이 활용하는 소프트웨어"를 선정 대상에서 제외한다. 학교·교육청의 해석은 다를 수 있으므로 소속 기관 지침을 우선한다.

## 입력하지 않는 정보 (교육부·교육청 「수행평가 시 AI 활용 관리 방안」 기준)
이름, 학번, 생년월일, 주소, 연락처, 가족관계, 타인의 사진. 파일 본문뿐 아니라 파일 이름과 문서 속성(작성자)에도 넣지 않는다.

## 자동 점검 규칙 (훅)
| 패턴 | 예 | 동작 |
|---|---|---|
| 주민·외국인등록번호 하이픈 형식(6자리-7자리) | 000000-0000000 | 입력 차단, 파일 쓰기 시 확인 요청 |
| 하이픈 없는 13자리 숫자 | 0000000000000 | 경고(바코드·주문번호일 수 있음) |
| 휴대전화 번호 | 010-0000-0000 | 경고 |
| "N학년 N반 N번" | "3학년 2반 15번" | 경고 |

- 경고는 진행을 막지 않고 AI에게 "가명 처리 먼저 제안" 지시를 덧붙인다. 이름은 보지 않으므로 이름이 붙어 있는지와 관계없이 "N학년 N반 N번" 형식이면 경고한다.
- 끄기: 환경변수 `BUNPIL_GUARD=off`, 또는 플러그인 비활성화. 수업 예시용 가짜 번호로 경고가 뜨는 것은 정상이다.
- 한계: 패턴 점검은 모든 개인정보를 잡지 못한다. 공백·전각 숫자·줄바꿈으로 나뉜 번호, 이름만 있는 명단, 사진은 잡지 못한다. 학번+이름, 번호 없는 "3학년 2반 김가명"도 점검하지 않는다. 상담 내용과 함께 사람이 판단해야 한다.

## 생활기록부
「2026학년도 학교생활기록부 기재요령」 유의사항: AI를 활용해 생성한 자료를 학교생활기록부 서술형 항목에 그대로 입력하는 행위는 금지된다. 교사가 쓴 문장의 윤문 보조는 최종 입력 전 교사 확인을 전제로 한다.

## 망 분리
업무용(업무망) PC에서는 인터넷이 막혀 있을 수 있다. 분필팩은 인터넷망 PC나 개인 기기에서 쓰고, 업무망 자료 반출은 학교 규정을 따른다.
