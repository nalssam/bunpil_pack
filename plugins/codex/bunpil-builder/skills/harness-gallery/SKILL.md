# 하네스 갤러리

잘 만든 하네스(에이전트 팀 + 스킬 + 지침) 예시를 가져와 내 업무에 맞게 고치는 것이 하네스 엔지니어링을 배우는 가장 빠른 길이다. 원본은 revfactory님의 harness-100(Apache-2.0) 한국어판이다.

개인정보 원칙: 학생 실명·학번·생년월일·주소·연락처·가족관계·사진 등 개인을 알아볼 수 있는 정보가 보이면 작업을 멈추고 '학생A'처럼 가명으로 바꾸자고 제안한다. 결과물에는 개인정보를 넣지 않는다.

## 절차

1. **고르기** — 선생님의 요청과 작업 폴더의 `CLAUDE.md`·`AGENTS.md`(학교급·업무)를 보고 `references/school-picks.md`에서 후보 2~3개를 이유 한 줄씩 붙여 제안한다. 목록에 없는 주제면 전체 목록(원본 `ko/` 폴더 이름)에서 찾는다.
2. **가져오기** — 선생님이 고르면, 원본을 임시 폴더로 받아 고른 예시의 `.claude/` 폴더만 작업 폴더에 복사한다.
   ```bash
   git clone --depth 1 --filter=blob:none --sparse https://github.com/revfactory/harness-100.git /tmp/harness-100
   git -C /tmp/harness-100 sparse-checkout set ko/57-exam-prep
   ```
   - 작업 폴더에 이미 `.claude/`가 있으면 덮어쓰지 않는다. `.claude/agents/`, `.claude/skills/` 안에 같은 이름이 있으면 멈추고 묻는다.
   - 예시의 `CLAUDE.md`는 작업 폴더의 `CLAUDE.md`를 덮어쓰지 않고 `harness-<이름>.md`로 저장한 뒤, 지침 파일에서 그 파일을 읽으라는 한 줄만 더한다. `AGENTS.md`에도 같은 줄을 더한다.
   - git이 없거나 받기에 실패하면 원본 주소(https://github.com/revfactory/harness-100/tree/main/ko)를 알려 주고, 선생님이 받은 폴더를 올리면 이어서 진행한다.
3. **학교에 맞게 고치기** — 가져온 에이전트·스킬 파일을 읽고 아래만 고친다. 고친 곳은 목록으로 보여 준다.
   - 대상: "고객·사용자" → "학생·학부모·교직원" 등 학교 말로
   - 산출물 형식: 학교에서 쓰는 형식(가정통신문, 기안문, 학습지, 이다체 보고서)으로
   - 개인정보 원칙 문장을 각 에이전트 지침 끝에 추가
   - 결과물은 초안이며 최종 판단은 교사가 한다는 문장 추가
4. **한 번 돌려 보기** — 예시 과제 하나를 정해 실행하고, 마음에 안 드는 점은 harness-fix로 규칙을 남기게 안내한다.
5. **출처 남기기** — `harness-<이름>.md` 맨 위에 "원본: revfactory/harness-100 ko/<폴더> (Apache-2.0), 분필팩 harness-gallery로 가져와 수정"을 적는다.

## 환경별 차이

- Claude Code·Cowork: `.claude/agents/`의 서브에이전트까지 그대로 쓴다.
- Codex: 서브에이전트 파일은 읽지 않는다. 에이전트 역할을 단계 목록으로 바꿔 `AGENTS.md`에 적고, 스킬 폴더는 `.agents/skills/`로 복사한다.
- 웹 채팅: 파일을 쓸 수 없으므로 고른 예시의 역할·단계를 요약해 프로젝트 지침에 붙여 넣을 글로 보여 준다.

모든 결과는 초안이며 최종 판단은 선생님이 한다.

## 점검

- [ ] 기존 `.claude/`, `CLAUDE.md`, `AGENTS.md`를 덮어쓰지 않았는가
- [ ] 학교 말과 형식으로 고친 곳을 목록으로 보여 주었는가
- [ ] 각 에이전트 지침에 개인정보 원칙 문장이 들어갔는가
- [ ] 출처(원본 폴더, Apache-2.0)를 남겼는가
- [ ] 임시로 받은 원본 폴더 위치를 알려 주었는가
