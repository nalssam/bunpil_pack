# 학교 업무에 맞는 harness-100 예시 (한국어판 `ko/` 폴더)

원본: https://github.com/revfactory/harness-100 (Apache-2.0). 각 폴더의 `.claude/`에 에이전트 팀·스킬·CLAUDE.md가 들어 있다.

| 폴더 | 원래 용도 | 학교에서 쓰는 예 |
|---|---|---|
| 08-course-builder | 커리큘럼→교안→퀴즈→실습과제 | 단원 재구성, 학교자율시간 교육과정, 연수 과정 설계 |
| 57-exam-prep | 출제경향→약점진단→맞춤학습→모의고사→오답분석 | 단원평가 대비 자료, 오답 유형별 보충 학습지 |
| 56-language-tutor | 레벨 테스트→커리큘럼→레슨→퀴즈→복습 | 영어·한국어(다문화) 수준별 수업 |
| 60-debate-simulator | 토론 시뮬레이션 | 사회·도덕 토론 수업 준비, 찬반 근거 자료 |
| 85-public-speaking | 연설문→발표대본→Q&A 예상답변 | 학생 발표 지도안, 교사 연수 발표 준비 |
| 13-presentation-designer | 기획→스토리보드→슬라이드→발표노트 | 수업·연수 슬라이드 |
| 82-report-generator | 데이터수집→분석→시각화→집필→요약 | 학교 행사 결과보고서, 교육과정 평가 보고서 |
| 93-feedback-analyzer | 피드백 감성분석·주제분류 | 학부모·학생 만족도 설문 분석 |
| 32-data-analysis | 탐색→정제→분석→시각화→보고서 | 기초학력 진단 결과(가명 처리 후) 분석 |
| 84-meeting-strategist | 안건구조→배경자료→의사결정→회의록 템플릿 | 교직원 협의회·학년 협의 준비 |
| 89-event-organizer | 컨셉→장소→프로그램→홍보→실행→사후평가 | 체험학습, 학교 축제, 독서 행사 |
| 95-procurement-docs | 요구사항→비교표→평가기준→계약 조건 | 물품 구입 품의, 업체 비교표 |
| 54-grant-writer | 공고 분석→사업계획→예산→제출 검증 | 교육청 공모사업 계획서 |
| 45-gov-funding-plan | 공고요건→사업성 작성→예산→증빙 | 선도학교·연구학교 운영계획서 |
| 83-sop-writer | 절차서→체크리스트→교육자료→버전관리 | 업무 인수인계서, 학교 업무 매뉴얼 |
| 91-onboarding-system | 체크리스트→교육→멘토→30-60-90일 계획 | 신규·전입 교사 안내 |
| 61-competency-modeler | 직무분석→역량사전→평가루브릭 | 역량 기반 평가 기준 설계 |
| 63-research-assistant | 학술 연구 보조 | 현장연구·실천연구 보고서 |
| 64-knowledge-base-builder | 조직 지식관리 체계 | 학년·부서 자료실 정리 |
| 33-text-processor | 대량 텍스트 요약·분류 | 공문·자료 대량 요약(개인정보 제외) |

## 가져오지 않는 것

- 학생 개인의 상담·생활지도 기록을 다루는 형태로 바꾸지 않는다.
- 생활기록부 서술형 문구를 만드는 형태로 바꾸지 않는다(2026 기재요령).
