# 예시: 초4 과학 '물의 상태 변화' 학습지 (3수준 요약)

요청 예: "초4 과학 물의 상태 변화 학습지 3수준으로 만들어 줘."
(성취기준 코드는 확실하지 않으면 쓰지 않는다. 이 예시에서는 코드를 생략했다.)

## 1단계: 핵심 개념 추출
1. 물의 세 가지 상태: 얼음(고체) · 물(액체) · 수증기(기체)
2. 열을 받으면 녹거나 증발하고, 열을 잃으면 얼거나 응결한다
3. 얼 때 부피가 늘어난다
4. 증발과 끓음은 다르다(표면에서 천천히 / 속에서도 기포가 생기며 빠르게)

## 2단계: 문항 설계표

| 개념 | 기본 | 보충 | 심화 |
|---|---|---|---|
| 세 가지 상태 | 빈칸 | 보기에서 고르기 | 일상 사례 분류 |
| 열을 받음/잃음 | 연결하기 | 그림 순서 + 힌트 | 이유 쓰기 |
| 부피 변화 | OX | OX + 그림 | 예측 서술 |
| 증발 vs 끓음 | 고르기 | 단계 질문 | 비교 서술 |

## 3단계: 학생용 문항 예 (일부)

**기본**
1. 얼음이 녹으면 ( ) 이 된다.
2. 물이 얼면 부피가 줄어든다. (O X)
3. 알맞은 것끼리 이어 보자: 얼음이 녹는다 — 열을 받는다 / 물이 언다 — 열을 잃는다

**보충**
1. 아래 보기에서 골라 써 보자. [보기: 얼음, 물, 수증기]
   - 손으로 만지면 차갑고 단단한 것: ( )
   - 눈에 보이지 않고 공기 중에 섞여 있는 것: ( )
2. 얼음이 녹을 때 열을 받을까, 잃을까? 힌트: 얼음을 손에 쥐면 어떻게 될까? ( )

**심화**
1. 겨울에 물이 가득 든 유리병을 베란다에 두었더니 병이 깨졌다. 그 까닭을 '부피'라는 낱말을 넣어 설명해 보자.
2. 빨래가 마르는 것과 주전자 물이 끓는 것은 같은 현상일까? 같은 점과 다른 점을 한 가지씩 써 보자.

## 4단계: 정답 파일 (별도 파일, 교사용)

| 수준 | 문항 | 정답 | 해설 |
|---|---|---|---|
| 기본 | 1 | 물 | 얼음(고체)이 열을 받아 녹으면 물(액체)이 된다 |
| 기본 | 2 | X | 물이 얼면 부피가 늘어난다 |
| 심화 | 1 | (채점 포인트) 물이 얼면 부피가 늘어난다 / 늘어난 부피가 병을 밀어 깨진다 | |
