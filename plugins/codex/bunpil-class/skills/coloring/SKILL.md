# 컬러링 도안 만들기

수업·창체·돌봄에서 쓸 흑백 선화 도안을 A4 SVG로 만든다. 모든 도안은 **독창적으로 새로 그린 것**이어야 한다.

## 시작하기 전에

1. 작업 폴더의 `CLAUDE.md` 또는 `AGENTS.md`를 읽는다. 학교급·학년·교과·문체를 반영한다.
2. **빠진 것만** 묻는다: 주제(소재), 학년(선 굵기와 영역 수를 정한다), 학습 연계 여부(낱말 색칠·번호 색칠), 장수.
3. 요청한 소재가 저작권 캐릭터·로고·실존 인물이면 아래 원칙대로 거절하고 대안을 제안한다.

## 지켜야 할 원칙

- 학생 실명·학번·생년월일·주소·연락처·가족관계·사진 등 개인을 알아볼 수 있는 정보가 보이면 작업을 멈추고 '학생A'처럼 가명으로 바꾸자고 제안한다. 결과물에는 개인정보를 넣지 않는다. 학급 학생의 **얼굴 사진을 본뜬 도안은 만들지 않는다.** 대신 얼굴 없는 일반 캐릭터 틀(원 모양 얼굴 + 빈 표정 칸)을 제안한다.
- 결과물은 모두 **초안**이다. 인쇄·배부는 교사가 확인 후 한다.
- 원본 파일(교과서 그림, 기존 도안, 업로드한 이미지)은 수정하지 않는다. 결과는 `outputs/` 아래 새 파일로 저장한다. 채팅 전용 환경이면 SVG 코드를 코드 블록으로 제시한다.
- **저작권**: 만화·애니메이션·게임·영화 캐릭터, 기업 로고·상표, 브랜드 마스코트를 그리지 않는다. "비슷하게" 그려 달라는 요청도 같다. 거절할 때는 짧게 이유(저작권·상표)를 말하고 **독창 대안**을 바로 제시한다. 예: 노란 전기 쥐 캐릭터 요청 → "번개 무늬 꼬리를 가진 둥근 노란 동물" 같은 새 캐릭터, 특정 학교·회사 마스코트 요청 → 학급 상징 도형 도안.
- 교과서 삽화를 따라 그리지 않는다. 같은 개념(예: 식물의 구조)을 새로 단순하게 그린다.
- 사실 소재(과일, 곤충, 행성, 문화재 등)는 형태가 정확해야 한다. 불확실하면 "형태 확인 필요"를 표시한다.

## 도안 규칙

상세 수치와 소재 목록은 `references/line-art-guide.md`를 읽는다.

- 선만 쓴다(`fill="none"`, 검정 stroke). 면을 칠하거나 그라데이션을 쓰지 않는다. 그림자·음영선·빗금도 쓰지 않는다.
- **모든 영역은 닫힌 도형**이다. 선이 끊겨 칠하면 번지는 틈이 없어야 한다.
- 학년별로 선 굵기와 영역 수를 조절한다.

| 학년 | 선 굵기(mm) | 영역 수 | 특징 |
|---|---|---|---|
| 1~2 | 1.6~2.0 | 5~10개 | 큰 도형 한두 개, 단순한 윤곽 |
| 3~4 | 1.2~1.5 | 10~20개 | 무늬 약간, 배경 소품 |
| 5~6·중등 | 0.8~1.0 | 20~40개 | 세부 무늬, 장면 구성 |

## 학습 연계 옵션

- **번호 색칠**: 영역마다 숫자를 넣고, 아래 안내 칸에 "1 주황, 2 초록…"을 적는다. 색은 6~8가지 이내, 숫자는 영역 안에 읽을 수 있는 크기(5~7 mm)로 넣는다.
- **낱말 색칠**: 영역 안에 학습 낱말(예: 수성·금성)을 넣고 "낱말에 맞는 색으로 칠해요"를 적는다. 정답 색을 미리 알려 주지 않는다.
- 학습 내용(사실)이 들어가면 정답표를 **별도 파일**로 만든다.

## 절차

1. **입력 확정**: 소재·학년·옵션을 한 줄로 정리해 알린다. 저작권 문제가 있으면 여기서 거절하고 대안을 제안한다.
2. **구도 설계**: 그림 영역(x 12~198, y 47~265 mm)에 들어갈 소재 배치를 정한다. 주요 소재는 영역의 60~80%를 차지하게 하고 여백을 남긴다.
3. **틀 복사**: `assets/coloring-frame.svg`를 복사한다. 제목을 바꾸고 이름 칸은 비운다. 번호 색칠이 아니면 `color-key` 그룹을 지운다.
4. **선화 작성**: `<g id="artwork">` 안에 닫힌 `path`/`ellipse`/`circle`/`rect`를 넣는다. 예시는 `assets/example-autumn-fruit.svg`(초1~2 가을 열매 번호 색칠).
5. **검사**: 아래 점검을 한다. 가능하면 `xml.etree.ElementTree`로 파싱해 오류가 없는지 확인하고, 변환 도구가 있으면 PNG로 렌더링해 눈으로 틈을 확인한다.
6. **저장**: `outputs/컬러링_<주제>_<학년>.svg`. PDF 변환 도구가 있으면 PDF도 만든다. 없으면 브라우저로 열어 인쇄(A4, 배율 100%)하라고 안내한다.
7. **보고**: 저장 위치, 영역 수, 번호 색칠이면 색 안내표를 알리고 초안임을 덧붙인다.

## 점검

- [ ] 소재가 저작권 캐릭터·로고·실존 인물이 아니고 새로 그린 도안인가
- [ ] 선만 있고(fill 없음) 모든 영역이 닫혀 있는가
- [ ] 선 굵기·영역 수가 학년에 맞는가 (저학년은 작은 영역이 없는가)
- [ ] 번호·낱말이 영역 안에 읽히는 크기로 들어 있고, 안내 칸과 일치하는가
- [ ] 이름 칸이 비어 있고 학생 이름·얼굴이 어디에도 없는가
- [ ] SVG가 오류 없이 열리고 A4(210x297mm)에 맞는가
