# 덱 HTML 작성 규칙

살아있는 PPT의 덱은 **HTML 한 파일**이다. `assets/deck-template.html`을 복사해 내용만 바꾸는 것이 가장 안전하다. 처음부터 쓰거나 다른 HTML을 가져올 때는 아래를 지킨다.

## 1. 뼈대

| 규칙 | 이유 |
|---|---|
| 슬라이드 하나 = `<section class="slide">` 하나 | 변환기가 이 수만큼 PowerPoint 슬라이드를 만든다 |
| 페이지가 열릴 때 `window.__LIVE_SLIDE__`(1부터)를 읽어 **그 슬라이드만** 보여 준다 | PowerPoint의 슬라이드마다 같은 HTML이 따로 실행된다 |
| 화면은 1920×1080 기준으로 그리고 창 크기에 맞춰 통째로 확대·축소한다 | 편집 화면(작게)과 슬라이드 쇼(전체 화면)에서 같은 모양 |
| 스타일·스크립트·그림을 한 파일에 담는다 | 파일 하나가 pptx 안에 저장된다 |

시작 틀의 `#stage`와 `#nav`, 맨 아래 "공통 스크립트"가 한 묶음으로 위 세 가지를 처리한다. 지우지 않는다. 4:3 화면이면 기준을 1440×1080으로 바꾸고 변환할 때 `--size 1440x1080`을 준다.

각 장의 첫 `<h1>`·`<h2>`·`<h3>`이 그 슬라이드의 대체 글(화면 읽기 프로그램용)과 문서 제목이 된다.

## 2. PowerPoint와 주고받기

추가 기능이 덱 안에 `window.liveSlide`를 넣어 준다(브라우저에서 그냥 열면 없다).

```js
if (window.liveSlide) {
  liveSlide.index;        // 지금 슬라이드 번호
  liveSlide.next();       // 다음 슬라이드로   (prev, first, last, goTo(3) 도 있다)
  liveSlide.keys = false; // ← → PageUp PageDown 을 덱이 직접 쓰고 싶을 때
}
```

Microsoft 365의 슬라이드 쇼에서 확인한 동작이다.

- 화면을 한 번 누르면 키보드가 HTML 쪽으로 넘어온다. 그래도 **← → PageUp PageDown**은 PowerPoint로 전달되어 장이 넘어간다. 덱이 그 키를 `preventDefault()`하면 전달하지 않는다.
- **글자 입력칸**에 커서가 있을 때는 ← → 가 글자 사이를 움직인다. PageDown·PageUp은 입력칸에서도 장을 넘긴다.
- **마우스로 만진 슬라이더**는 만진 뒤 키보드를 놓아 주어, 바로 ← → 로 넘길 수 있다(확인함). 체크 상자·선택 단추·목록·손가락 누르기도 같게 만들었지만 실제 PowerPoint에서는 확인하지 못했다. Tab으로 골라 키보드로 조작할 때는 화살표가 그 부품에 쓰인다.
- 화면을 누른 뒤에는 **Esc를 두 번** 눌러야 슬라이드 쇼가 끝난다(첫 번째는 HTML이 받는다).
- 시작 틀 오른쪽 아래의 ← → 단추는 PowerPoint의 장을 넘긴다(`liveSlide.prev()` / `liveSlide.next()`). 덱에 따로 "다음" 단추를 두려면 `onclick="window.liveSlide && liveSlide.next()"`.
- 리모컨, 전자칠판의 손가락 누르기, 발표자 보기에서의 동작은 확인하지 못했다.

## 3. 활동 부품 (시작 틀에 들어 있는 것)

| 부품 | 쓰임 | 고칠 곳 |
|---|---|---|
| 뒤집는 카드 `.flip` | 생각해 보고 눌러 확인 | `.q`(질문) `.a`(답) |
| 슬라이더 조작 | 값을 바꾸면 그림이 달라지는 탐구 | `bar()` 함수 |
| 4지선다 퀴즈 | 확인 문제, 해설 | `QS` 배열(`q` 문제, `o` 보기, `a` 정답 순서(0부터), `why` 해설). 글자는 HTML로 쓴다. 정답을 고르면 더 눌러도 바뀌지 않는다 |
| 타이머 | 모둠 활동 시간 | `data-t`(초) |
| 번호 뽑기 | 발표 순서 | `nmax`(인원), 화면의 − + 단추로도 바꾼다 — 이름이 아니라 번호만 |
| 정리 체크 | 배운 것 함께 확인 | `.check` 문장 |
| 세로 분수 `.fr` | 분수 표기 | HTML에서는 `<span class="fr">1/2</span>`, 스크립트에서는 `fr(1, 2)` |
| ↺ 단추 `#rs` | 지금 장을 처음 상태로(실제 PowerPoint 편집 화면에서 확인함. 슬라이드 쇼에서는 확인하지 못함) | 그대로 둔다 |

- 부품을 뺄 때는 그 HTML과 "부품별 동작"의 같은 덩어리(`part('#…', …)`)를 함께 지운다. 부품 하나가 고장 나도 나머지는 동작하고, 변환기가 고장 난 부품 이름과 줄 번호를 알려 준다.
- 새 부품을 만들 때: 한 장에 학생 활동 하나(타이머·번호 뽑기 같은 교사 도구는 함께 둘 수 있다), 단추는 크게(전자칠판에서 손가락으로 누른다), 글자는 1920 기준 30px 이상, 색만으로 정답·오답을 구분하지 않는다(기호·글자 함께).
- 한글이 낱말 중간에서 끊기지 않게 `body`의 `word-break:keep-all`을 지우지 않는다.
- PowerPoint는 **파일을 열어 둔 동안 장마다 눌러 둔 상태를 그대로 둔다**(편집 화면에서 눌러 본 것이 슬라이드 쇼에도 남는다). 수업 전에 눌러 봤다면 ↺ 단추로 되돌리거나 파일을 닫았다 다시 연다.

## 4. PowerPoint 안에서 달라지는 것

덱은 PowerPoint 안에서 격리된 틀(샌드박스)로 실행된다. 브라우저에서 그냥 열 때와 다른 점이다.

| 쓰려는 것 | PowerPoint 안에서 | 권하는 방법 |
|---|---|---|
| 슬라이드 사이에 값 넘기기(점수 누적 등) | 안 된다. 장마다 따로 실행된다 | 점수를 세는 활동은 **한 장 안에** 여러 문제를 넣고 그 장의 단추로 넘긴다 |
| `localStorage`·`sessionStorage` | 그 장이 떠 있는 동안만 기억하는 대역으로 바뀐다. 장끼리 나누지 못하고 파일을 다시 열면 사라진다 | 변수에 둔다. "다음에도 기억"하는 기능은 뺀다 |
| 쿠키 | 무시된다 | 쓰지 않는다 |
| `alert()` | 창 대신 화면 위쪽에 잠깐 뜨는 알림 글자로 바뀐다 | 화면 안에 글자로 보여 준다 |
| `confirm()` `prompt()` | 묻지 않는다(`confirm`은 항상 예, `prompt`는 기본값) | 화면 안의 단추·입력칸으로 바꾼다 |
| 바깥 주소 링크(`https://…`) | 누르면 그 컴퓨터의 기본 브라우저가 열린다 | 수업 흐름이 끊기므로 꼭 필요할 때만 |
| `#` 링크 | 같은 장 안에서 움직인다 | 그대로 써도 된다 |
| 다른 파일로 가는 링크(`page2.html`), 새 창 | 아무 일도 일어나지 않는다 | 내용을 덱 안에 넣는다 |
| 마이크·카메라·위치, 파일 내려받기 | 지원하지 않는다 | — |
| 큰 영상·소리 파일 | HTML 저장 크기가 3.0MB를 넘으면 변환이 멈춘다(한글 한 글자는 6으로 센다) | 영상은 PowerPoint의 다른 슬라이드에 넣는다 |
| 학생 이름·사진 | 넣지 않는다 | 번호·가명·도형으로 대신한다 |

변환기는 `alert`·`localStorage` 같은 것을 발견하면 "알림:" 줄로 알려 준다. 고칠 수 있으면 표의 권하는 방법으로 바꾼다.

## 5. 그림과 글꼴, 바깥 파일

- 그림·CSS·JS를 따로 둔 파일(`<img src="img/a.png">`, `<script src="quiz.js">` 등)은 **덱이 있는 폴더 안에 있을 때** 변환기가 HTML 안으로 넣어 준다. 폴더 밖의 파일은 넣지 않고 알려 주므로 덱 폴더로 옮긴다.
- 스크립트에서 경로를 만들어 넣는 그림(`img.src = 'img/' + name`)은 변환기가 넣지 못한다(알아챌 수 있으면 "합치지 못한 로컬 참조"로 알린다). HTML에 직접 `<img src>`로 쓰거나 그림을 글자(data 주소)로 넣는다.
- 슬라이드 수만큼 한 벌씩 저장되므로 그림은 작게(한 장 200KB 이하 권장) 쓴다. 도형·SVG가 가장 가볍다.
- 글꼴은 컴퓨터에 있는 것을 쓴다(`"Pretendard","Malgun Gothic","Apple SD Gothic Neo",sans-serif`).
- **인터넷 주소에서 불러오는 것(CDN 라이브러리, 웹 글꼴)은 쓰지 않는다.** 학교망에서 막히거나 느릴 수 있다. 꼭 필요한 라이브러리는 파일로 내려받아 덱 옆에 두고 주소를 파일 이름으로 바꾸면 pptx 안에 함께 들어간다. 변환기가 "인터넷에서 불러오는 주소"를 알려 주면 이렇게 없앤다.
- 저작권 있는 캐릭터·교과서 삽화·출처를 모르는 그림은 넣지 않는다.

## 6. 발표자 노트

`<section class="slide" data-notes="교사 발문, 예상 반응, 시간, 정답">`이 PowerPoint 메모란으로 들어간다. 줄을 바꾸려면 속성 안에서 그대로 줄을 바꾼다. 슬라이드 안의 `<aside class="notes">…</aside>`도 노트가 되지만, **화면에 보이지 않게 직접 숨겨야 한다**(`<aside class="notes" hidden>`). 숨기지 않으면 정답이 화면에 나온다. 형성평가 정답처럼 학생에게 보이면 안 되는 것은 노트에만 쓴다.

## 7. 미리보기 그림

변환기는 슬라이드마다 **첫 화면**을 그림으로 찍어 넣는다. 추가 기능이 없는 컴퓨터, 오래된 PowerPoint, 인쇄·PDF에서는 이 그림이 보인다.

- **누르기 전 첫 화면만 봐도 무엇을 하는 장인지 알 수 있게** 만든다(빈 화면에서 시작하지 않는다).
- 첫 화면에 정답이 보이지 않게 한다.
- PowerPoint에서 파일을 **저장하면 그 순간의 화면이 미리보기 그림으로 바뀐다.** 정답을 펼쳐 둔 채 저장하면 그림에 정답이 남는다. 저장하기 전에 ↺ 로 되돌리거나, 고칠 일이 있으면 `deck.html`을 고쳐 다시 변환한다.

## 8. 가진 HTML을 살아있는 덱으로 바꾸기

원본은 그대로 두고 사본으로 작업한다. 먼저 교사에게 묻는다: 화면을 어떻게 나눌지, 여러 화면에 걸친 점수 같은 기능을 유지할지(유지하려면 그 화면들을 한 장에 넣는다).

**권하는 방법 — 시작 틀로 옮긴다.**

1. `assets/deck-template.html`을 복사하고, 본보기 슬라이드의 내용을 지운다(`#stage`·`#nav`·공통 스크립트는 둔다).
2. 원본의 화면 하나하나를 `<section class="slide">`로 옮긴다. 아래로 길게 내려 읽는 페이지는 한 화면 분량씩 나눈다(슬라이드는 높이가 정해져 있고, 미리보기 그림에는 첫 화면만 담긴다).
3. 원본의 스타일과 스크립트를 가져오되, 4번 표에 걸리는 것(저장소, `alert`, 바깥 라이브러리, 다른 파일로 가는 링크)을 바꾼다. 제이쿼리 같은 라이브러리는 파일로 내려받아 덱 옆에 두거나 쓰지 않게 고친다.
4. 장마다 `data-notes`를 쓴다.

**틀을 쓰지 않을 때의 최소 코드.** 원본 구조를 그대로 두고 싶으면 화면을 `<section class="slide">`로 나누고 아래를 `</body>` 바로 앞에 넣는다. 시작 틀의 "공통 스크립트"만 떼어 붙이면 동작하지 않는다(`#stage`와 `#nav`가 있어야 한다).

```html
<style>.slide{display:none}.slide.on{display:block}</style>
<script>
  // PowerPoint 안에서는 window.__LIVE_SLIDE__ 번호의 장만 보이고, 브라우저에서는 ← → 로 넘겨 본다.
  (function () {
    var s = document.querySelectorAll('.slide'), n = window.__LIVE_SLIDE__ || 1;
    function show(i) {
      n = Math.max(1, Math.min(s.length, i));
      for (var k = 0; k < s.length; k++) { s[k].classList.toggle('on', k === n - 1); }
    }
    show(n);
    if (typeof window.__LIVE_SLIDE__ !== 'number') {
      addEventListener('keydown', function (e) {
        if (e.key === 'ArrowRight') { show(n + 1); }
        if (e.key === 'ArrowLeft') { show(n - 1); }
      });
    }
  })();
</script>
```

바꿀 때 자주 걸리는 것:

- **점수를 세는 퀴즈**는 한 장 안에서 해결한다. `var score = 0`을 두고 정답 단추에서 `score++` 한 뒤, 마지막 문제 다음에 같은 장 안의 결과 칸에 점수를 보여 준다. 시작 틀의 퀴즈 부품(`QS`)에는 점수 계산이 없으니 필요하면 직접 더한다.
- **그림**은 크기를 정하지 않으면 원래 크기로 커서 화면을 덮을 수 있다. CSS에 `img{max-width:100%;height:auto}`를 넣고, 변환 뒤 `sheet.jpg`로 확인한다.
- 이름·학번을 **입력받는 칸**은 뺀다(PowerPoint 안에서는 저장되지 않고 개인정보를 만들 수 있다).
- 4:3 화면이면 `#stage`의 1920×1080과 공통 스크립트의 1920·1080(두 곳)을 1440×1080으로 고치고 변환할 때 `--size 1440x1080`을 준다.
- PowerPoint 안에서 달라지는 것은 위 **4번 표**를 본다(저장소·알림창·다른 파일로 가는 링크 등).

이 최소 코드는 화면 크기를 맞춰 주지 않는다. 원본이 창 크기에 맞게 그려지는 페이지인지 4단계(브라우저)와 미리보기 그림으로 확인한다.
