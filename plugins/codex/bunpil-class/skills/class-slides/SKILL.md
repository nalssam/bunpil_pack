# 수업 슬라이드 만들기

교사가 수업을 진행할 때 띄우는 슬라이드 초안을 만든다. 교과서 내용은 **요약·재구성**하고 원문과 그림을 통째로 옮기지 않는다.

## 시작하기 전에

1. 작업 폴더의 `CLAUDE.md` 또는 `AGENTS.md`를 읽는다. 학교급, 학년, 교과, 문체, 선호 디자인(색, 글꼴 크기)이 있으면 반영한다.
2. **빠진 것만** 묻는다: 학년·교과·단원·차시 목표, 수업 시간, 슬라이드 분량(기본 8~12장), 교과서 쪽(교사가 제공하는 PDF·PNG).
3. 제공된 쪽을 읽을 수 없거나(흐림, 잘림, 암호화) 글자를 판독할 수 없으면 **추측으로 채우지 않는다.** 읽은 부분과 못 읽은 부분을 나눠 알리고, 교사에게 다시 올리거나 핵심 문장을 직접 입력해 달라고 요청한다.

## 지켜야 할 원칙

- 학생 실명·학번·생년월일·주소·연락처·가족관계·사진 등 개인을 알아볼 수 있는 정보가 보이면 작업을 멈추고 '학생A'처럼 가명으로 바꾸자고 제안한다. 결과물에는 개인정보를 넣지 않는다. 학생 얼굴이 나온 사진·캡처가 첨부되면 슬라이드에 넣지 않고, 이름·얼굴이 없는 자료로 바꾸자고 제안한다.
- 결과물은 모두 **초안**이다. 수업에서 띄우기 전 내용 확인은 교사가 한다.
- 원본 파일(교과서 PDF, 기존 PPT)은 수정하지 않는다. 결과는 `outputs/` 아래 새 파일로 저장한다. 채팅 전용 환경이면 슬라이드 구성안을 대화에 제시한다.
- **저작권**: 교과서의 본문 문장과 삽화·사진을 슬라이드에 통째로 붙여 넣지 않는다. 개념은 짧은 문장으로 요약하고, 그림은 새로 만든 도형·아이콘·교사가 권리를 가진 자료로 대체한다. 출처는 슬라이드 맨 아래에 `참고: ○○ 교과서 ○쪽` 형태로 적는다. 교사가 수업용으로 보유한 자료라는 전제는 인정하되, **재배포용 파일에는 원본 쪽 이미지를 넣지 않는다.**
- 인터넷 이미지는 라이선스를 확인할 수 없으면 쓰지 않는다. 도형·아이콘·이모지 수준의 간단한 그림으로 대신한다.
- 사실·수치는 교과서 쪽에서 확인된 것만 쓴다. 확인 못 한 내용은 "확인 필요"로 표시한다.

## 슬라이드 흐름

기본 구성(8~12장). 자세한 슬라이드별 내용과 발문 예는 `references/slide-flow.md`를 읽는다.

| 순서 | 슬라이드 | 내용 |
|---|---|---|
| 1 | 표지 | 단원·차시 제목, 학년·교과 (교사 이름은 교사가 직접 입력) |
| 2 | 학습목표 | 목표 1~2문장, 오늘 할 일 3줄 |
| 3 | 동기유발 | 질문 1개 + 이미지 자리(도형·아이콘) |
| 4~7 | 활동 1~3 | 활동 안내, 시간, 방법, 모둠 역할, 핵심 개념 요약 |
| 8 | 정리 | 핵심 개념 3줄, 학생이 말해 볼 질문 |
| 9 | 형성평가 | 1~3문항 (정답은 발표자 노트에만) |
| 10 | 차시 예고(선택) | 다음 시간 준비물 |

모든 슬라이드의 **발표자 노트**에 교사 발문(열린 질문 1~2개), 예상 반응, 시간 안내, 유의점을 쓴다. 슬라이드 본문은 글자를 줄이고(한 장 40자 안팎, 3줄 이내) 글자 크기는 교실 뒤에서 읽히는 크기(본문 28pt 이상)로 한다.

## 절차

1. **자료 읽기**: 교사가 준 쪽을 읽고 핵심 개념·활동·용어를 목록으로 뽑는다. 못 읽은 곳은 표시한다.
2. **구성안 확인**: 슬라이드 제목과 한 줄 내용 목록(구성안)을 교사에게 보여 주고 수정 요청이 없으면 진행한다.
3. **파일 만들기**
   - 플랫폼에 **PPTX 생성 기능**(예: pptx 스킬·문서 생성 도구)이 있으면 그것으로 `.pptx`를 만든다. 발표자 노트 기능이 있으면 노트에 발문을 넣는다.
   - 없으면 `assets/slides-fallback.html`을 복사해 슬라이드별 HTML로 만든다. 화살표 키로 넘기고 `N` 키로 발표자 노트를 보이게 한다. 인쇄하면 한 장에 한 슬라이드가 나온다.
4. **점검** 후 `outputs/수업슬라이드_<교과>_<단원>_<차시>.pptx` (또는 `.html`)로 저장한다.
5. **보고**: 저장 위치, 슬라이드 수, 교과서에서 요약한 부분과 못 읽은 부분, 교사가 확인할 곳을 알린다.

## 점검

- [ ] 슬라이드에 교과서 문장·삽화를 통째로 옮기지 않았고, 출처를 적었는가
- [ ] 표지·학습목표·동기유발·활동·정리·형성평가 흐름이 다 있는가
- [ ] 모든 슬라이드 발표자 노트에 교사 발문이 있는가
- [ ] 글자가 작거나 많은 슬라이드(40자 초과, 28pt 미만)가 없는가
- [ ] 형성평가 정답이 슬라이드 본문이 아니라 노트에만 있는가
- [ ] 학생 이름·얼굴·사진이 없고, 초안임을 알렸는가
