# 예시: 고1 논술형 평가 (주장하는 글쓰기) 루브릭 초안

가정: 고등학교 1학년 국어, 주제에 대해 주장하는 글(600~800자)을 쓰는 수행평가. 4수준. 성취기준 코드는 확실하지 않아 내용만 적는다. (교사가 학교 평가계획의 코드로 바꾼다.)

| 평가요소 | 성취기준 연결 | 매우 잘함 (4) | 잘함 (3) | 보통 (2) | 노력 필요 (1) |
|---|---|---|---|---|---|
| 주장의 명료성 | 주장하는 글에서 쓰는 사람의 입장을 분명히 드러낸다(확인 필요) | 주장을 첫 문단에서 한 문장으로 밝히고 마지막 문단에서 같은 의미로 다시 확인했다 | 주장을 한 문장으로 밝혔으나 마무리에서 다시 확인하지 않았다 | 주장이 글 속에 있으나 한 문장으로 정리되지 않고 여러 문장에 흩어져 있다 | 주장을 찾을 수 없거나 글 안에서 서로 다른 주장이 섞여 있다 |
| 근거의 타당성 | 타당한 근거를 들어 주장을 뒷받침한다(확인 필요) | 서로 다른 근거 3개 이상을 들고 각각에 사례나 자료를 붙였다 | 근거 2개를 들고 한 근거 이상에 사례나 자료를 붙였다 | 근거 1개를 들었으나 주장과의 연결을 설명하지 못했다 | 근거 없이 느낌·의견만 반복했다 |
| 글의 짜임 | 처음-중간-끝의 짜임으로 글을 조직한다(확인 필요) | 세 부분이 모두 있고 문단마다 중심 문장이 있으며 이음말로 연결했다 | 세 부분이 있고 문단 중심 문장은 있으나 이음말이 부족하다 | 세 부분 중 한 부분이 빠졌거나 문단 구분이 불분명하다 | 문단 구분 없이 이어 썼다 |
| 표현과 표기 | 맞춤법과 문장 호응에 맞게 쓴다(확인 필요) | 맞춤법·띄어쓰기 오류가 2개 이하이고 문장 호응이 모두 맞다 | 오류가 3~5개이고 의미 전달에 지장이 없다 | 오류가 6~10개이거나 의미가 모호한 문장이 있다 | 오류가 많아(11개 이상) 읽기 어렵다 |

비중(예시): 주장 25% / 근거 35% / 짜임 25% / 표현 15% — 교사가 정한다.

## 이 예시에서 쓴 차이 기준
- 주장의 명료성: 위치와 확인 여부
- 근거: 개수와 사례 유무
- 짜임: 요소 완성도
- 표현과 표기: 오류 개수 (교사가 학년·분량에 맞게 조정)

## 학생 자기평가 쉬운 말 버전 (고1)

| 확인할 것 | 나는… | ○ △ × |
|---|---|---|
| 주장 | 내 주장을 한 문장으로 썼다 | |
| 주장 | 마지막에 내 주장을 다시 말했다 | |
| 근거 | 이유를 2개 이상 썼다 | |
| 근거 | 이유마다 예를 하나씩 붙였다 | |
| 짜임 | 처음·중간·끝으로 나눠 썼다 | |
| 표현 | 다시 읽으며 틀린 글자를 고쳤다 | |
