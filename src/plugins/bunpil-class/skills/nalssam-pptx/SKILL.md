# 날쌤 스타일 PPTX (nalssam-pptx)

「AI Agent 시대, 교실은 어떻게 달라지는가?」(40장) 덱의 모양과 느낌을 그대로 재현하는 절차와 코드다. 대상은 교사·교육행정직 공무원·교육전문직·디지털 튜터·방과후 강사 연수(원격연수 포함). 결과물은 16:9 .pptx, **대본은 슬라이드 메모란**, 장표마다 알맞은 이미지, 아래 규격 고정.

철학은 pptx-maker와 같다(결론 문장 제목 · 한 장 한 메시지 · 모든 장에 대본 · 지어낸 숫자 금지). 다만 python-pptx로 직접 조립해 좌표와 장표 유형이 고정되므로 늘 같은 얼굴이 나온다. 날쌤 스타일을 요청받으면 pptx-maker보다 이 스킬을 우선한다.

개인정보 원칙: 학생 실명·학번·생년월일·주소·연락처·가족관계·사진 등 개인을 알아볼 수 있는 정보가 보이면 작업을 멈추고 '학생A'처럼 가명으로 바꾸자고 제안한다. 결과물에는 개인정보를 넣지 않는다.

## 들어 있는 파일

| 파일 | 하는 일 |
|---|---|
| `scripts/nalssam_lib.py` | 조립 헬퍼(색·좌표·장표 유형 함수) |
| `scripts/build_example.py` | build.py 뼈대(3장 예시). 작업 폴더에 `build.py`로 복사해 장을 늘린다 |
| `scripts/embed_fonts.py` | Pretendard 전체 글꼴 임베드(마지막 저장 단계) |
| `scripts/fixbg.py` | 생성 이미지 배경을 덱 배경색에 맞추기 |
| `scripts/qa.py` | 납품 전 자동 점검 |
| `scripts/render_check.py` | 렌더링 모아보기(12장씩) |
| `scripts/edit_helpers.py` | 기존 덱의 문구만 바꾸기 |
| `references/style.md` | 색·글꼴·좌표 표, 장표 유형 표 |
| `references/images.md` | 이미지 3종 만드는 법(클레이 오브젝트·셰프 마스코트·화면 캡처) |

스크립트는 이 스킬 폴더의 `scripts/`에서 작업 폴더로 복사해 쓴다(작업 폴더에 `nalssam_lib.py`가 있어야 `build.py`가 불러온다).

## 1. 시작 전 확인
요청에 이미 있는 것은 다시 묻지 않는다. 모자라면 한 번에(최대 4문항) 묻는다.
① 행사: 이름·날짜·시간·대상(일정은 캘린더로 확인), 공동 강사 표기 여부 ② 분량: 총 시간·장수 ③ 대본: **녹화 낭독형**(분당 300~350자, 그대로 읽는 글) / **라이브 요점형**(분당 약 100자 + [시연]·[참여] 큐) ④ 이미지: 새로 생성 / 가진 이미지만.
예약 실행처럼 물을 사람이 없으면 합리적 가정을 첫 줄에 밝히고 진행한다.

## 2. 스타일 한눈에
- **분위기**: 웜 오프화이트 바탕(`FBFAF6`) 위에 네이비 글씨, 틸 포인트, 코랄 한 방울. 여백이 넉넉하다. 카드는 흰 바탕 + 얇은 베이지 테두리의 **납작한 둥근 상자(그림자 없음)**.
- **글꼴**: Pretendard(본문) · **Pretendard ExtraBold**(제목·표지) · Pretendard Medium(쪽번호). 반드시 임베드한다.
- **문장 규칙**: 제목 = 결론 한 문장(30자 안팎). 키커 = "01 섹션명" 작은 틸 글씨. 한 장 한 메시지, 근거 2~5개. 아래에 **민트 띠**로 한 줄 결론 또는 "교사가 지키는 것". 같은 유형 3장 연속 금지.
- **바닥글**: `행사명  |  강사 이름  |  2026. 10. 31.(토)` + 오른쪽 `NN / 총장수`(표지는 쪽번호 없음). 끼워 넣은 장은 `13-1 / 35`처럼 라벨, 분모는 본편 총장수.
- **이미지 3종**: ⓐ 3D 클레이·세라믹 오브젝트(개념 장표) ⓑ 셰프 마스코트 스토리 장면(전면 16:9) ⓒ 실제 화면 캡처(둥근 모서리 + 얇은 테두리). 그림에는 로고·상표·실존 캐릭터를 넣지 않는다(도구 이름은 슬라이드의 글자 칩으로). 자세히는 `references/images.md`.
- **말투**: 대본은 구어체 존댓말. 낭독용이라 영문 약어는 소리 나는 대로 쓴다(CLAUDE.md → 클로드닷엠디).
- **강사 소개**: 작업 폴더의 지침 파일(CLAUDE.md·AGENTS.md, 분필팩 setup으로 만든 것)에 적힌 이름·소속·학교급을 쓴다. 날쌤 본인 덱이면 날쌤 프로필(반송초 창의융합진로부장 박준호 @nalssam, 몽당분필 대표, 프로필 QR https://nalssam-profile.vercel.app/ , 분필팩 nalssam-bunpil.vercel.app)을 쓴다.
- **대상별 소재 힌트**: 교사(수업 설계·자료·평가·피드백·학부모 소통) / 교육행정직(공문·계획서·보고서·회의록·예산·민원·엑셀 정리) / 교육전문직(정책 연구·장학자료·연수 기획·설문 분석) / 디지털 튜터(학생 맞춤 지원·도구 안내·학습 데이터·상담 기록) / 방과후 강사(프로그램 계획·활동 안내문·학부모 소통·만족도 조사). 어느 대상이든 "학생 실명·민감정보·비공개 공문은 외부 AI에 올리지 않는다"는 원칙을 한 장에 넣는다.

## 3. 작업 순서
1. **확인**(§1) → 일정·이전 원고를 캘린더·드라이브·작업 폴더에서 찾는다.
2. **구조·시간표**: 장 목록(제목 = 결론 문장)과 장별 분. 기본 골격: 표지 → (소개) → 오늘의 질문·학습목표 → 본문(개념 → 사례 → 시연 → 실습) → 개조식 요약 → 내일 시작할 한 가지 → 출처 → 감사 + QR. 마지막 장 종료 시각 = 행사 종료(쉬는 시간 포함)인지 검산한다. 길면 장 목록을 먼저 보여 준다.
3. **조사**: 최신 사실·수치·제품 정보는 웹 검색으로 확인하고 출처를 적는다. 논문은 저자·연도·저널·권호까지. 확인 못 한 것은 쓰지 않고, 예시는 '(가상)'으로 표시한다.
4. **이미지**(`references/images.md`)를 먼저 일괄 요청해 두고, 기다리는 동안 캡처 수집과 대본 초안을 쓴다.
5. **조립**: `build.py` 하나에 장마다 `notes()`까지 쓴다(`scripts/build_example.py`가 뼈대). 마지막에 `assert n == TOTAL`.
6. **글꼴 임베드**: `python embed_fonts.py raw.pptx 최종.pptx` — 항상 마지막 저장 단계. 고칠 일이 생기면 raw를 다시 만들어 이 단계부터 반복한다.
7. **점검**(아래 '## 점검') → 수정 → 반복.
8. **전달**: 파일과 한두 문장(장수 · 총 시간 · 가상 예시 · 확인 못 한 사실 · 글꼴을 임베드해 따로 설치하지 않아도 됨).

## 4. 환경 준비 (새 컴퓨터에서 한 번)
```bash
python3 -c "import pptx, fontTools, PIL, numpy" 2>/dev/null || pip install python-pptx fonttools pillow numpy
pip install qrcode zxing-cpp            # QR이 필요할 때
mkdir -p ~/.local/share/fonts && cd "$(mktemp -d)" && npm pack pretendard@1.3.9 >/dev/null 2>&1 \
 && tar -xzf pretendard-1.3.9.tgz --wildcards 'package/dist/public/static/alternative/Pretendard-*.ttf' \
 && cp package/dist/public/static/alternative/Pretendard-*.ttf ~/.local/share/fonts/ && fc-cache -f \
 && fc-list | grep -c Pretendard            # 9가 나오면 성공 (72MB 받음)
```
- 시스템 파이썬이 설치를 막으면(`externally-managed`) `pip install --user …` 또는 `uv pip`을 쓴다.
- Windows는 받은 Pretendard-*.ttf를 `%LOCALAPPDATA%\Microsoft\Windows\Fonts`에 넣고, `embed_fonts.py`·`qa.py`에 글꼴 폴더를 그 경로로 준다(`embed_fonts.py in out 글꼴폴더`).
- 렌더링 점검에는 LibreOffice(`soffice`)와 `pdftoppm`(poppler)이 필요하다. 없으면 PowerPoint로 PDF를 저장해 장마다 이미지로 바꿔 본다.

## 5. 대본(메모) 규칙
- 메모란(`notes()`)에 쓴다. 첫 줄 `7장 · 3분 · 10:17~10:20`(끼워 넣은 장은 `13-1장 · …`), 빈 줄, 구어체 본문. 쉬는 시간은 `[쉬는 시간 10분 · 11:01~11:11]`, 시연·참여는 `[시연]` `[참여]` 큐.
- 길이: 녹화 낭독형 분당 300~350자(공백 포함), 라이브 요점형 분당 약 100자. 장별 분을 합쳐 행사 시간과 맞는지 코드로 검산한다.
- 첫 장에 인사·소개, 마지막 장에 마무리 인사 + QR 안내. 출처 장은 "출처는 화면으로 대신하겠습니다" 한 줄이면 된다.
- 한 장의 대본은 그 장의 제목(결론)을 다시 한 번 말로 닫는다. 숫자·연도·인용은 지어내지 않는다(예시는 가상이라고 말한다). 학생 실명 금지.

## 6. 기존 덱을 다른 행사로 바꿀 때
새로 만들지 말고 문구만 바꾼다(이미지·배치·사용자가 손본 곳 보존). ① 새 행사 일정·주제·대상 확인 ② 옛 행사 단어 목록 작성(기관명·직군어) ③ `edit_helpers`의 `find`(정확히 1개일 때만)·`set_text`·`sub`로 교체 ④ 바닥글·쪽번호·키커·대본(시간표 포함) 일괄 갱신 ⑤ 줄 수가 늘어난 곳 점검 ⑥ `qa.py --ban 옛단어…` + 렌더링 ⑦ PowerPoint로 다시 저장한 덱은 임베드가 부분(subset)으로 바뀌었을 수 있으니 마지막에 `embed_fonts.py`를 다시 돌린다.

## 7. 함정 (실제로 겪은 것)
1. **부분 임베드 글꼴**: 쓴 글자만 담은 글꼴이 심겨 있으면 새로 쓴 글자가 얇은 대체 글꼴로 보인다 → 마지막에 항상 `embed_fonts.py`.
2. **테마 그림자**: python-pptx 기본 템플릿은 도형에 그림자를 입힌다 → `_flat()`이 지운다. 도형은 반드시 `box/chip/dot/hline`으로 만든다.
3. 타임라인 점선이 연도 글자를 가린다 → 연도 상자에 배경색 채움(코드 반영). 긴 질문은 두 줄로 쪼개 사진과 겹치지 않게, 큰 인용문은 수동으로 3줄.
4. 부제는 장당 한 줄. compact 헤더가 아니면 본문을 y 2.0 아래에 둔다.
5. 스크린샷의 개인정보·사이드바 글자는 크롭한다. QR은 `make_qr`의 디코드 검증을 통과해야 한다.
6. 이미지 생성 결과 주소는 만료될 수 있다 → 즉시 파일로 저장하고 덱에는 파일만 넣는다.
7. 날짜·요일·일정은 캘린더·검색으로 확인한다. 장이 늘면 쪽번호 분모·대본 첫 줄 시각을 함께 갱신한다.
8. 근거 슬라이드는 하단 8.5pt로 출처(저자·연도·저널)를 달고 출처 장에 모은다. 확인되지 않은 수치는 쓰지 않는다.

## 점검
- `python qa.py 최종.pptx [--ban 옛단어1,옛단어2]` — 오류(대본 없음·금칙어)는 0이어야 하고, 주의(글자 넘침 추정·슬라이드 밖·허용 밖 글꼴·제목 36자 초과·쪽번호 분모 불일치)는 하나씩 설명할 수 있어야 한다.
- `python render_check.py 최종.pptx pv` → `pv/sheet*.jpg`를 **전부** 본다. 겹침 · 잘림 · 제목이 두 줄로 넘어가 부제와 닿음 · 글자가 얇게 보임(글꼴 대체) · 이미지 가장자리 색 차이 · 한글 깨짐 · 쪽번호를 확인하고, 의심 장은 `pdftoppm -jpeg -r 100 -f N -l N pv/최종.pdf pv/zoom`으로 확대한다. LibreOffice는 한영 혼용 글자 사이가 PowerPoint보다 넓게 보이는데 글꼴 문제가 아니다.
- 대본 합계 시간이 행사 시간과 맞는지, 모든 장에 대본이 있는지, 학생 실명·민감정보가 없는지 확인한다.
- 결과물은 초안이다. 사실·숫자·일정은 강사가 최종 확인한다고 전달할 때 밝힌다.
