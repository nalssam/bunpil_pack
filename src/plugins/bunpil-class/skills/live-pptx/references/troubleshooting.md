# 화면이 움직이지 않을 때 · 다른 컴퓨터에서 쓸 때

여기 적은 화면과 문구는 실제 PowerPoint(Windows)에서 확인한 것이다. 확인하지 못한 것은 그렇게 적었다.

## 다른 컴퓨터에 등록하기 (스킬 없이 한 줄)

교실 PC나 동료 컴퓨터에는 분필팩이 없어도 된다. 아래 한 줄을 실행하고 **PowerPoint를 완전히 종료했다가 다시 연다.** 지금 로그인한 사용자에게만 등록되고 관리자 권한을 쓰지 않도록 만들었다(일반 사용자 계정에서는 시험하지 못했다).

Windows — 시작 메뉴에서 PowerShell을 열고 붙여넣는다.

```
powershell -NoProfile -Command "irm https://nalssam-bunpil.vercel.app/live-html/register.ps1 | iex"
```

Mac — 터미널을 열고 붙여넣는다(Mac에서는 확인하지 못했다).

```
curl -fsSL https://nalssam-bunpil.vercel.app/live-html/register.sh | sh
```

지울 때는 Windows

```
powershell -NoProfile -Command "irm https://nalssam-bunpil.vercel.app/live-html/unregister.ps1 | iex"
```

Mac

```
curl -fsSL https://nalssam-bunpil.vercel.app/live-html/register.sh | sh -s -- --remove
```

안내 페이지(같은 내용, 복사 단추): https://nalssam-bunpil.vercel.app/live-html/

명령이 무엇을 하는지 먼저 보고 싶으면 `https://nalssam-bunpil.vercel.app/live-html/register.ps1`(Windows) 또는 `register.sh`(Mac) 주소를 브라우저로 열어 내용을 읽어 볼 수 있다.

등록이 하는 일: 추가 기능 설정 파일(`manifest.xml`, 주소만 적힌 작은 파일)을 내려받아 Windows는 `%LOCALAPPDATA%\LiveHTML`에 두고 레지스트리 `HKCU\Software\Microsoft\Office\16.0\WEF\Developer`에 그 경로를 적는다. Mac은 `~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef`에 둔다. 프로그램을 설치하지 않는다.

## 어느 PowerPoint에서 어디까지 되나

| PowerPoint (Windows) | 편집 화면 | 슬라이드 쇼(전체 화면) |
|---|---|---|
| Microsoft 365(구독형, 최신 채널 16.0.20625에서 확인) | 눌러진다 | 눌러진다 — 클릭, 글자 입력, 화면의 ← → 단추, 키로 넘기기 |
| Office LTSC 2024(16.0.17932) | 눌러진다 | 화면만 보인다. 편집 화면에서 아직 열어 보지 않은 장은 희거나 검게 나올 수 있다 |
| Office LTSC 2021(16.0.14334) | 눌러진다 | 화면만 보인다(편집 화면에서 눌러 둔 상태 그대로) |
| Office 2019(학교·기관이 한꺼번에 설치한 판, 16.0.10417) | 미리보기 그림 + 검은 안내 줄 | 같다 |

- 창 모드 쇼(슬라이드 쇼 설정의 "웹 형식으로 진행(창)")에서는 어느 버전이든 화면만 보이고 눌러지지 않는다. **전체 화면 슬라이드 쇼**를 쓴다.
- 시험한 컴퓨터에는 그래픽 카드가 없었다. 그래픽 카드가 있는 LTSC 컴퓨터에서 다를 수 있는지는 확인하지 못했다.
- 확인하지 못한 곳: 다른 업데이트 채널이나 더 오래된 Microsoft 365(기관이 업데이트를 늦춘 곳은 발표 전에 슬라이드 쇼로 한 번 눌러 본다), Mac PowerPoint, 웹용 PowerPoint, 낱개로 산 Office 2021·2024, Office 2016, 발표자 보기, 펜·레이저 포인터, 전자칠판의 손가락 누르기, 휴대폰·태블릿 앱, 한쇼, 구글 슬라이드. PDF 저장·인쇄·동영상 내보내기는 미리보기 그림으로 나올 것으로 예상한다.
- 버전 확인: PowerPoint의 파일 → 계정 → 제품 정보. "Microsoft 365"라고 나오면 구독형이다.

## 슬라이드 쇼에서 눌러지지 않는 컴퓨터라면 — 브라우저로 발표

pptx와 함께 받은 `deck-browser.html`(그림·글자가 한 파일에 합쳐진 것)을 Edge나 Chrome으로 연다. `deck.html`만 받았고 그림이 깨져 보이면 그림 폴더와 함께 폴더째 받거나, 만든 사람에게 `deck-browser.html`을 달라고 한다. **F11**로 전체 화면, **← →** 로 넘긴다. 등록도 추가 기능도 필요 없고, 같은 화면이 그대로 움직인다. PowerPoint 발표 중간에 잠깐 쓸 때는 Alt+Tab으로 오간다.

## 웹용 PowerPoint (확인하지 못함)

웹용 PowerPoint에서는 기본으로 그림이 보일 것으로 예상한다. Microsoft 안내에 따르면 홈 → 추가 기능 → 기타 설정 → 내 추가 기능 업로드(Upload My Add-in)에서 `manifest.xml`을 올릴 수 있으나, 이 덱이 거기서 움직이는지는 확인하지 못했다. 브라우저에서 `deck-browser.html`을 여는 쪽이 확실하다.

## 덱을 고칠 때

pptx 안의 HTML을 직접 고치지 않는다. 원본 `deck.html`을 고친 뒤 다시 변환하면 된다(등록은 다시 하지 않아도 된다. `deck-browser.html`도 함께 새로 만들어진다). PowerPoint에서 슬라이드 순서를 바꾸거나 일부를 지워도 되고, 보통 슬라이드를 사이에 끼워도 된다. HTML 한 장만 바꾸고 싶으면 편집 화면에서 그 슬라이드 **왼쪽 위**의 작은 톱니바퀴(⚙)를 눌러 HTML 파일과 보여 줄 화면 번호를 다시 고른다. 이렇게 고르는 파일은 그림·스크립트가 한 파일에 들어 있어야 한다.

## 개인정보와 보안

- HTML은 pptx 파일 안에 저장되고, 추가 기능 페이지는 그것을 꺼내 화면에 그릴 뿐 어디로도 보내지 않는다. 다만 pptx를 받은 사람은 안의 HTML을 볼 수 있다.
- 추가 기능 페이지(`https://nalssam-bunpil.vercel.app/live-html/app.html`)와 Microsoft의 Office 구성 요소(`appsforoffice.microsoft.com`)를 불러올 때 일반적인 웹 접속 기록이 그 서버에 남는다.
- 덱은 격리된 틀에서 실행되어 컴퓨터의 파일, 다른 슬라이드, 저장소·쿠키에 접근하지 못하고 파일을 내려받게 하지도 못한다. 바깥 주소 링크는 사람이 눌렀을 때만 기본 브라우저로 열린다.
- 덱 안의 스크립트가 PowerPoint 기능(문서 읽기·쓰기)을 직접 부를 수 없다는 것은 실제 PowerPoint에서 확인했다. 다만 덱의 스크립트는 일반 웹 페이지처럼 인터넷으로 요청을 보낼 수 있다.
- 변환기는 덱이 있는 폴더 안의 파일만 pptx에 넣는다(폴더 밖 파일은 `--allow-outside`를 줄 때만).
- 출처를 모르는 사람이 준 살아있는 PPT는 일반 웹 페이지처럼 화면에 무엇이든 그릴 수 있으므로, 믿을 수 있는 사람이 만든 파일만 연다.
