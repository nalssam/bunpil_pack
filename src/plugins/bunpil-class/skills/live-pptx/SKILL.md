# 살아있는 PPT 만들기 (live-pptx)

슬라이드 안에서 HTML이 **실제로 실행되는** PowerPoint 파일을 만든다. 그림이 아니라 웹 페이지라서 교사와 학생이 화면을 눌러 볼 수 있다. 편집 화면에서도, 슬라이드 쇼에서도 동작한다.

원리는 세 줄이다. ① 수업 내용을 HTML 한 파일(덱)로 쓴다. ② 변환 스크립트가 그 HTML을 pptx 파일 **안에** 저장하고, 슬라이드마다 "Live HTML" 추가 기능 틀을 놓는다. ③ 발표 PC의 PowerPoint가 그 틀에서 HTML을 꺼내 실행한다.

개인정보 원칙: 학생 실명·학번·생년월일·주소·연락처·가족관계·사진 등 개인을 알아볼 수 있는 정보가 보이면 작업을 멈추고 '학생A'처럼 가명으로 바꾸자고 제안한다. 결과물에는 개인정보를 넣지 않는다.

## 먼저 알릴 것 (만들기 전에 교사에게 말한다)

| 조건 | 내용 |
|---|---|
| PowerPoint 버전 | Windows·Mac의 **Microsoft 365 또는 Office 2021 이상**. Office 2016·2019는 웹 엔진이 오래되어 그림만 보인다 |
| 추가 기능 등록 | 발표할 컴퓨터마다 **한 번** 등록한다(아래 5단계). 등록하지 않은 컴퓨터에서는 같은 자리에 미리보기 그림이 보인다 |
| 인터넷 | 발표할 때 인터넷이 연결되어 있어야 화면이 움직인다 |
| 안 되는 곳 | 휴대폰·태블릿 앱, 한쇼·구글 슬라이드, PDF·인쇄, 발표자 보기 화면에서는 그림으로 보인다 |

이 조건이 맞지 않으면(예: 교실 PC가 Office 2019) 보통 PPT(class-slides)나 브라우저로 띄우는 HTML을 권한다.

## 들어 있는 파일

| 파일 | 하는 일 |
|---|---|
| `assets/deck-template.html` | 시작 틀(분수 수업 6장: 표지·뒤집는 카드·슬라이더 조작·퀴즈·타이머와 뽑기·정리) |
| `scripts/build_live_pptx.py` | HTML → pptx 변환(로컬 그림·CSS·JS 합치기, 미리보기 촬영, 발표자 노트) |
| `scripts/qa_live_pptx.py` | 만든 pptx 점검 |
| `scripts/register_addin.py` | 이 컴퓨터의 PowerPoint에 추가 기능 등록·해제·상태 확인 |
| `assets/manifest.xml` | 추가 기능 설정 파일(등록할 때 쓴다) |
| `references/deck-guide.md` | 덱 HTML 규칙과 활동 부품 |
| `references/troubleshooting.md` | 화면이 안 움직일 때, 동료에게 줄 때, 지울 때 |

## 1. 시작 전 확인

1. 작업 폴더의 `CLAUDE.md` 또는 `AGENTS.md`를 읽어 학교급·학년·교과·문체·선호 색을 반영한다.
2. **빠진 것만** 한 번에 묻는다(최대 4문항): ① 학년·교과·단원과 차시 목표 ② 장수(기본 6~8장)와 넣고 싶은 활동(퀴즈·조작·타이머·뽑기·카드) ③ 발표 PC(Windows/Mac, PowerPoint 버전) ④ 이미 가진 HTML이 있는지.
3. 교과서 쪽이나 자료를 받았으면 요약·재구성한다. 본문과 삽화를 통째로 옮기지 않고, 못 읽은 부분은 추측하지 않는다.

## 2. 덱 HTML 쓰기

1. `assets/deck-template.html`을 `outputs/<이름>/deck.html`로 복사한다.
2. 구성안(장 제목 + 그 장에서 누르는 것)을 먼저 보여 주고, 수정 요청이 없으면 내용을 바꾼다.
3. 규칙은 `references/deck-guide.md`를 따른다. 꼭 지킬 것:
   - 슬라이드 하나 = `<section class="slide">` 하나, **한 장에 활동 하나**. 슬라이드끼리는 값을 주고받지 못한다.
   - 맨 아래 "공통 스크립트"는 지우지 않는다(슬라이드 번호 `window.__LIVE_SLIDE__` 처리).
   - 글꼴·그림·스크립트를 인터넷 주소에서 불러오지 않는다. 그림 파일은 덱 옆에 두면 변환기가 합쳐 준다.
   - 교사 발문은 `data-notes="…"`에 쓴다. 정답은 화면이 아니라 노트·해설에 둔다.
   - 번호 뽑기는 번호만 쓴다. 학생 이름 목록을 덱에 넣지 않는다.
4. 가진 HTML을 바꾸는 경우: 화면을 `<section class="slide">`로 나누고 공통 스크립트를 붙인다. 원본은 고치지 않고 사본으로 작업한다.

## 3. 변환

```bash
python -c "import pptx" 2>/dev/null || pip install python-pptx        # 처음 한 번
python <스킬 폴더>/scripts/build_live_pptx.py outputs/<이름>/deck.html -o outputs/<이름>/<이름>.pptx --shots outputs/<이름>/preview
```

- Windows에서 `python`이 없으면 `py`를 쓴다. 설치가 막히면(`externally-managed`) `pip install --user python-pptx`.
- 미리보기 그림은 컴퓨터의 Edge·Chrome으로 찍는다. 못 찾으면 안내 그림으로 대신하므로 `--browser "<실행 파일 경로>"`를 준다.
- 변환기가 알려 주는 것을 그대로 전하고 고친다: 합친 로컬 파일, 찾지 못한 파일, **인터넷에서 불러오는 주소**(있으면 덱에서 없앤다), **슬라이드를 열 때 난 스크립트 오류**(있으면 고치고 다시 변환), 용량 주의.
- `--shots`를 주면 장마다 첫 화면 PNG와 모아보기 `sheet.jpg`가 저장된다. **전부 열어 본다**: 겹침·잘림·글자 넘침·빈 화면이 없는지.
- HTML이 약 1.9MB를 넘으면 변환을 멈춘다. 큰 그림을 줄인다.

## 4. 브라우저로 먼저 보기

`deck.html`을 브라우저로 열어 ← → 키로 넘기며 모든 단추·슬라이더·입력칸을 눌러 본다. 브라우저를 조작할 수 있는 도구가 있으면 직접 눌러 보고, 없으면 교사에게 `deck.html`을 열어 눌러 봐 달라고 한다. 여기서 안 되는 것은 PowerPoint에서도 안 된다.

## 5. 추가 기능 등록 (발표할 컴퓨터마다 한 번)

등록은 컴퓨터 설정을 바꾸는 일이므로 **무엇을 하는지 말하고 동의를 받은 뒤** 실행한다: "현재 사용자 계정에만, 관리자 권한 없이 PowerPoint 추가 기능 한 개를 등록합니다. 언제든 지울 수 있습니다."

```bash
python <스킬 폴더>/scripts/register_addin.py            # 등록
python <스킬 폴더>/scripts/register_addin.py --status   # 확인
python <스킬 폴더>/scripts/register_addin.py --remove   # 지우기
```

등록 뒤 **PowerPoint를 완전히 종료했다가 다시 연다.** 다른 컴퓨터(교실 PC, 동료)에서는 스킬 없이 한 줄로 등록한다 — `references/troubleshooting.md`의 "다른 컴퓨터에 등록하기".

## 6. 전달

파일 위치와 함께 짧게 알린다: 장수 · 장마다 누를 수 있는 것 · 발표자 노트 유무 · 발표 PC 준비(등록, 인터넷, 버전) · 등록 안 된 곳에서는 그림으로 보인다는 점 · 확인하지 못한 것. **실제 PowerPoint에서 열어 보는 마지막 확인은 교사가 한다**(파일을 열고 슬라이드 쇼로 모든 장을 한 번씩 눌러 본다).

화면이 움직이지 않으면 `references/troubleshooting.md`를 읽고 증상에 맞는 항목을 안내한다.

## 지켜야 할 원칙

- 결과물은 모두 **초안**이다. 수업에서 쓰기 전 내용·정답·동작 확인은 교사가 한다.
- 원본 파일은 고치지 않는다. 결과는 `outputs/` 아래 새 파일로 저장한다. 채팅 전용 환경이면 덱 HTML을 대화에 제시하고 변환 방법을 안내한다.
- HTML은 pptx 파일 안에만 저장된다. 추가 기능 페이지는 덱 내용을 어디로도 보내지 않는다. 그래도 파일을 받는 사람은 안의 HTML을 볼 수 있으므로 공개하면 안 되는 내용을 넣지 않는다.
- 사실·수치·정답은 교사가 준 자료에서 확인된 것만 쓴다. 확인 못 한 내용은 "확인 필요"로 표시한다.
- 교과서 본문·삽화, 저작권 있는 캐릭터, 출처를 모르는 인터넷 그림을 넣지 않는다. 출처는 화면 아래에 `참고: ○○ 교과서 ○쪽`으로 적는다.
- 컴퓨터에 새로 설치·등록할 때는 이름과 이유를 말하고 동의를 받는다. 관리자 권한이 필요한 일은 직접 하지 않고 정보 담당 선생님께 안내한다.

## 점검

- [ ] `python <스킬 폴더>/scripts/qa_live_pptx.py outputs/<이름>/<이름>.pptx` 가 **오류 0건**인가(주의는 하나씩 설명할 수 있어야 한다)
- [ ] 변환기가 인터넷에서 불러오는 주소·찾지 못한 파일·스크립트 오류를 알리지 않았고, 슬라이드 수가 `<section class="slide">` 수와 같은가
- [ ] 미리보기 모아보기(`sheet.jpg`)를 전부 봤는가 — 겹침·잘림·빈 화면이 없고, 첫 화면만 봐도 무엇을 하는 장인지 알 수 있는가
- [ ] 브라우저에서 모든 장의 단추·슬라이더·입력이 동작했는가(직접 못 했으면 교사에게 확인을 부탁했는가)
- [ ] 모든 장에 발표자 노트(교사 발문)가 있고 정답이 미리 보이지 않으며, 학생 이름·사진과 교과서 본문·삽화가 들어가지 않았는가
- [ ] PowerPoint 버전·추가 기능 등록·인터넷 조건과 초안임을 알렸는가
