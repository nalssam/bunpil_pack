# 학습지 만들기

교사가 수업에 쓸 A4 학습지를 수준별로 만든다. 학생용 파일과 정답 파일은 항상 따로 만든다.

## 시작하기 전에

1. 작업 폴더의 `CLAUDE.md` 또는 `AGENTS.md`를 읽는다. 학교급, 학년, 교과, 문체(이다체·해요체), 선호 서식이 있으면 그대로 따른다.
2. 파일이 없거나 비어 있으면 아래 중 **빠진 것만** 한 번에 묻는다. 이미 말한 것은 다시 묻지 않는다.
   - 학년·교과 (없으면 반드시 묻는다. 학년을 추측해서 만들지 않는다)
   - 주제 또는 성취기준
   - 수준: 기본·보충·심화 중 무엇을 만들지 (기본값은 기본 1종)
   - 문항 수(기본 8~10문항)와 형식(빈칸·OX·연결·단답·서술)

## 지켜야 할 원칙

- 학생 실명·학번·생년월일·주소·연락처·가족관계·사진 등 개인을 알아볼 수 있는 정보가 보이면 작업을 멈추고 '학생A'처럼 가명으로 바꾸자고 제안한다. 결과물에는 개인정보를 넣지 않는다.
- 결과물은 모두 **초안**이다. 출력·배부는 교사가 내용을 확인한 뒤 직접 한다.
- 원본 파일(교과서 파일, 기존 학습지 등)은 수정하지 않는다. 결과는 `outputs/` 아래 새 파일로 저장한다. 채팅만 되는 환경이면 대화에 제시한다.
- 이름·번호 칸은 **빈 칸**으로 둔다. 학생 이름을 미리 채우지 않는다.
- 정답·해설은 학생용 파일에 절대 섞지 않는다. 학생용 파일의 숨은 요소, 주석, 거꾸로 쓴 글, 접힌 영역에도 넣지 않는다.
- 성취기준 코드(예: 4과01-02)는 확실할 때만 쓴다. 확실하지 않으면 코드를 쓰지 않고 "성취기준 확인 필요"라고 적는다.
- 교과서 문장·그림을 통째로 옮기지 않는다. 개념을 새 문장과 새 예시로 다시 쓴다.
- 학생이 AI에 직접 입력하거나 AI가 학생을 채점하는 용도로 설계하지 않는다. 교사가 쓰는 자료만 만든다.

## 수준 구분

세 수준은 **같은 학습 목표**를 다른 방식으로 확인한다. 보충이 낮은 학년용이라는 뜻이 아니다.

| 수준 | 방향 | 만드는 방법 |
|---|---|---|
| 기본 | 핵심 개념 이해·확인 | 교과 핵심 용어를 쓰는 빈칸·OX·연결·단답 중심 |
| 보충 | 단계를 쪼개고 단서를 준다 | 보기·그림 자리·첫 글자 힌트 제공, 문장은 짧고 쉬운 낱말로, 문항당 한 가지만 묻기 |
| 심화 | 적용·추론·설명 | 새 상황에 적용, 이유 쓰기, 자료 해석, 한 문항에 두 개념 연결 |

자세한 문항 유형과 예시는 `references/levels-and-items.md`, 완성 예시는 `references/example-water-states.md`를 읽는다.

## 절차 (프롬프트 체이닝)

1. **입력 확정**: 학년·교과·주제·수준·문항 수를 정리해 한 줄로 교사에게 확인한다.
2. **핵심 개념 추출**: 주제에서 학생이 알아야 할 핵심 개념·용어를 3~5개 뽑는다. 교사가 고칠 수 있게 먼저 보여 주고, 지시가 없으면 그대로 진행한다.
3. **문항 설계표**: 개념 × 문항 형식 × 수준 표를 만든다. 개념마다 최소 1문항이 있어야 한다.
4. **학생용 학습지 작성**: `assets/a4-template.html`을 복사해 제목·학년·교과·문항을 채운다. 글자 크기는 저학년 14pt 이상, 중학년 12~13pt, 고학년 이상 11~12pt로 한다. 답 쓰는 칸은 넉넉히 둔다.
5. **정답·해설 작성**: 별도 파일로 만든다. 각 문항에 정답과 한두 문장 해설, 자주 틀리는 오개념을 적는다.
6. **점검**: 아래 점검 목록을 확인하고 고친다.
7. **저장**: `outputs/학습지_<주제>_<수준>.html`, `outputs/학습지_<주제>_<수준>_정답.html`. 3수준이면 학생용 3개 + 정답 3개(또는 정답 1개에 수준별 구역)로 만든다. 정답 파일 이름에 반드시 `정답`을 넣는다.
8. **출력 안내**: 브라우저로 열어 인쇄(배율 100%, 용지 A4)하거나 PDF로 저장하라고 안내한다. PDF 변환 도구가 있으면 변환하되, 없으면 안내만 한다.

## 결과 보고

저장한 파일 목록, 만든 수준과 문항 수, 교사가 꼭 확인할 곳(사실 관계, 성취기준 코드, 그림 자리)을 짧게 알린다. "초안이니 확인 후 사용"을 한 줄로 덧붙인다.

## 점검

결과물을 내기 전에 확인한다.

- [ ] 학년·교과·수준이 요청과 맞고, 용어와 문장 길이가 그 학년에 맞는가
- [ ] 학생용 파일 어디에도 정답·풀이가 없고, 정답 파일이 따로 있는가
- [ ] 모든 핵심 개념이 최소 한 문항에서 다뤄지고, 문항 수가 요청과 같은가
- [ ] 과학·사회 등의 사실, 수치, 단위가 맞는가 (불확실하면 "확인 필요"로 표시)
- [ ] 성취기준 코드를 확실한 것만 썼는가
- [ ] 이름·번호 칸이 비어 있고 개인정보가 어디에도 없는가
- [ ] A4 한 장(또는 요청한 쪽수)에 들어가고 답 칸이 충분한가
