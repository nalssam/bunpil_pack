# 수준별 문항 설계 안내

## 1. 문항 형식 고르기

| 형식 | 알맞은 때 | 주의 |
|---|---|---|
| 빈칸 채우기 | 핵심 용어 확인 | 한 문항에 빈칸 1~2개. 정답이 하나로 정해지는 낱말만 |
| OX | 흔한 오개념 점검 | 문장은 한 가지 사실만. "항상", "절대" 같은 함정 표현 줄이기 |
| 고르기 | 개념 구분 | 보기는 3~4개, 오답은 실제 학생이 하는 오개념에서 만든다 |
| 연결하기 | 용어-뜻, 원인-결과 | 한쪽 항목 수를 같게. 3~5쌍 |
| 단답 | 이름·값 쓰기 | 단위 칸을 따로 둔다 |
| 서술 | 이유 설명, 적용 | 심화에서 주로. 답 칸을 넉넉히, 채점 기준은 정답 파일에 |
| 자료 해석 | 표·그래프 읽기 | 자료는 새로 만든 값으로. 교과서 표를 그대로 옮기지 않는다 |

## 2. 수준별 변형 규칙 (같은 개념, 다른 문항)

### 기본
- 학습 목표를 그대로 확인한다.
- 교과서에 나온 용어를 사용한다.
- 문항 수 8~10개, 형식은 2~3가지 섞는다.

### 보충
- 문항을 작은 단계로 나눈다. (예: "상태 변화를 설명하시오" → "①어떤 상태에서 ②어떤 상태로 ③열을 받았나, 잃었나")
- 힌트 줄 또는 보기 상자를 준다. 첫 글자 힌트도 가능하다.
- 문장은 한 문장 15어절 안팎, 어려운 한자어는 풀어 쓴다.
- 그림·표 자리를 넣어 눈으로 확인하게 한다.
- 문항 수는 6~8개로 줄여 시간 압박을 낮춘다. 마지막에 "스스로 점검" 체크칸을 넣을 수 있다.

### 심화
- 새로운 상황(처음 보는 사례)에 개념을 적용하게 한다.
- "왜 그렇게 생각하나요?"처럼 이유를 쓰게 한다.
- 두 개념을 연결하거나 실험 설계·예측 문항을 넣는다.
- 문항 수 5~7개, 서술형 비중을 높인다.

## 3. 정답·해설 파일 구성

```
제목: ○○ 정답과 해설 (교사용)
문항 | 정답 | 해설(1~2문장) | 자주 틀리는 점
```
- 서술형은 "채점 포인트"를 2~3개 항목으로 적는다. (점수 부여는 교사가 정한다.)
- 파일 맨 위에 "교사용 — 학생에게 배부하지 않는다"를 적는다.

## 4. 해서는 안 되는 것

- 학생 실명·학번이 들어간 사례 문장. 사례 인물은 "민지", "철수"처럼 흔한 가상 이름이거나 "학생A"를 쓴다. (실제 학급 학생 이름과 겹치지 않는지 교사가 확인한다.)
- 교과서 본문·삽화 복사. 개념과 구조만 참고해 새로 쓴다.
- 출처가 불분명한 통계 수치. 필요하면 "예시 값"이라고 표시한다.
