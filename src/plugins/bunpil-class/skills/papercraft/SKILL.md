# 페이퍼 크래프트 전개도 만들기

수업 활동용 입체 만들기 자료를 A4 SVG 전개도로 만든다. 도형 좌표는 `scripts/net.py`가 계산한다.

## 시작하기 전에

1. 작업 폴더의 `CLAUDE.md` 또는 `AGENTS.md`를 읽는다. 학교급·학년·교과·문체를 반영한다.
2. **빠진 것만** 묻는다: 만들 입체(주사위·상자·원기둥 등), 크기(mm, 모르면 아래 권장값), 면에 넣을 이름·주제, 학년(가위질 난이도 판단).
3. 요청한 입체가 다섯 가지 기본 도형(정육면체, 직육면체, 삼각기둥, 원기둥, 사각뿔)이 아니면, 가장 가까운 기본 도형에 주제를 입히는 대안을 제안한다. (예: 집 모양 → 직육면체 + 지붕 삼각기둥)

## 지켜야 할 원칙

- 학생 실명·학번·생년월일·주소·연락처·가족관계·사진 등 개인을 알아볼 수 있는 정보가 보이면 작업을 멈추고 '학생A'처럼 가명으로 바꾸자고 제안한다. 결과물에는 개인정보를 넣지 않는다. 학생 이름 각인 요청은 이름을 넣지 않고 `--name-box`로 **빈 이름 칸**만 둔다. 학생이 직접 쓰게 한다.
- 결과물은 모두 **초안**이다. 인쇄 전 교사가 선 종류와 크기를 확인하고, 시험 제작을 1개 해 본다.
- 원본 파일은 수정하지 않는다. 결과는 `outputs/` 아래 새 파일로 저장한다. 채팅 전용 환경이면 SVG 코드를 코드 블록으로 제시한다.
- **저작권**: 만화·게임·애니메이션 캐릭터, 기업 로고·상표, 연예인 얼굴은 면에 그리지 않는다. 요청이 오면 짧게 이유를 알리고 **독창적 대안**(예: 둥근 눈의 동그란 동물 캐릭터, 별·행성 아이콘, 학급 상징 도형)을 제안한다. 실제 천체·동식물·문화재 같은 공공의 소재는 쓸 수 있다.
- 선 규약은 아래와 같고, 모든 전개도에서 같게 쓴다. 자세한 설명은 `references/svg-conventions.md`.

## 선 규약

| 표시 | SVG class | 뜻 |
|---|---|---|
| 검정 실선 | `cut` | 가위로 자른다 |
| 검정 점선 | `fold` | 접는다(인쇄면 쪽에서 산접기: 그림이 있는 면이 바깥이 된다) |
| 회색 면 | `glue` | 풀칠하는 날개. 풀을 바르고 안쪽에 붙인다 |
| 글자 | `label` | 면 이름·주제 |

## 절차

1. **크기 정하기**: 권장값은 정육면체 모서리 40~60 mm, 직육면체 가로 60·높이 40·깊이 30 mm 안팎, 원기둥 반지름 20~30 mm·높이 50~70 mm, 삼각기둥 한 변 40 mm·길이 70 mm, 사각뿔 밑면 50~60 mm·높이 50 mm. 전개도가 A4 여백(10 mm)보다 크면 자동으로 줄어든다. 줄었다는 메시지가 나오면 실제 크기가 줄었음을 교사에게 알린다.
2. **전개도 만들기**: 스크립트를 실행한다. 스크립트 폴더는 이 스킬 폴더 아래 `scripts/net.py`이다.
   ```
   python3 net.py cube --size 50 --labels "수성,금성,지구,화성,목성,토성" -o outputs/전개도_정육면체.svg
   python3 net.py cuboid --width 60 --height 40 --depth 30 --name-box -o outputs/전개도_직육면체.svg
   python3 net.py prism --size 40 --height 70 -o outputs/전개도_삼각기둥.svg
   python3 net.py cylinder --radius 25 --height 60 -o outputs/전개도_원기둥.svg
   python3 net.py pyramid --size 60 --height 50 -o outputs/전개도_사각뿔.svg
   ```
   - 옵션: `--title`(머리말 제목), `--name-box`(이름 쓰는 줄), `--tab`(풀칠 날개 너비), `--no-guide`(범례 끄기), `--check`(만든 SVG를 다시 읽어 검사).
   - 라벨 순서: 정육면체·직육면체는 앞·오른쪽·뒤·왼쪽·위·아래, 삼각기둥은 직사각형 3개·위 삼각형·아래 삼각형, 원기둥은 옆면·위 원·아래 원, 사각뿔은 밑면과 위·오른쪽·아래·왼쪽 삼각형.
   - 스크립트를 실행할 수 없는 환경(채팅 전용)이면 `references/svg-conventions.md`의 규약대로 SVG를 직접 작성하고, 좌표를 한 번 더 검산한다.
3. **주제 장식(선택)**: 면에 이름만 넣는 것이 기본이다. 간단한 그림(별, 원, 동물 얼굴)을 더하려면 SVG에 `<g id="decor">`로 **선화(stroke만, 닫힌 도형)**를 추가한다. 선은 전개도 선과 구분되도록 가는 회색(`#888`, 0.25 mm)으로 한다. 재단·접기 선과 헷갈리는 굵은 검정 선은 쓰지 않는다.
4. **만드는 방법 1쪽**: `references/assembly-guide.md`를 바탕으로 학년에 맞게 고쳐 `outputs/만들기방법_<도형>.html`(또는 .md)로 저장한다. 준비물, 순서, 안전 유의점(가위·칼 사용), 풀 바르는 요령을 쓴다.
5. **PDF 변환(선택)**: 변환 도구(rsvg-convert, inkscape, 브라우저 인쇄 등)가 있으면 PDF로 변환한다. 없으면 "SVG를 브라우저로 열어 인쇄 → 용지 A4, 배율 100%(맞춤 아님), 여백 없음 또는 기본"이라고 안내한다.
6. **점검** 후 파일 목록과 확인 사항을 보고한다.

## 점검

- [ ] 모든 면의 선이 맞물리는가(접는 선은 모두 점선, 바깥 둘레는 실선) — 스크립트 출력의 `--check` 결과가 통과했는가
- [ ] 풀칠 날개가 모든 이음매에 하나씩 있고 다른 면과 겹치지 않는가 (정육면체 7개, 삼각기둥 5개, 사각뿔 4개, 원기둥은 옆면 1개 + 원 둘레 날개)
- [ ] 크기가 A4 안에 들어가고, 줄어든 경우 그 사실을 알렸는가
- [ ] 저작권 캐릭터·로고·학생 이름이 들어가지 않았는가
- [ ] 만드는 방법에 가위 안전 유의점이 있고 학년에 맞는 쉬운 말인가
- [ ] 초안임을 알렸고, 시험 제작 1개를 권했는가
