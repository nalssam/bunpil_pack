# 만드는 방법 1쪽 (학생용 안내 틀)

학년에 맞게 문장을 고친다. 저학년은 그림 위주로 짧게, 고학년은 접합 순서를 더 자세히.

## 제목: {{입체 이름}} 만들기

**준비물**: 전개도 인쇄물(A4, 실제 크기), 가위, 풀, 색연필(선택), 자(선택)

**선을 읽어요**
- 실선 ─── 가위로 잘라요
- 점선 - - - 접어요
- 회색 부분 풀을 발라 붙여요

**순서**
1. 이름 칸에 자기 이름을 써요. (교사가 미리 쓰지 않는다)
2. 면에 색을 칠하거나 꾸며요. 접기 전에 칠하는 것이 쉬워요.
3. 실선을 따라 바깥 둘레를 잘라요. 회색 날개도 같이 남겨요.
4. 점선을 자에 대고 손톱이나 볼펜 뚜껑으로 눌러 접는 길을 만들어요.
5. 점선을 모두 인쇄면 쪽에서 산접기로 접어요. 그림이 있는 면이 바깥이 되고, 점선이 산 모양으로 솟아요. 풀칠 날개는 안쪽으로 들어가요.
6. 회색 날개에 풀을 얇게 바르고, 이웃한 면의 **안쪽**에 붙여요. 한 곳씩 붙이며 말려 있는 곳이 없는지 살펴요.
7. 마지막 이음매는 손이 안쪽에 닿기 어려워요. 연필이나 자를 날개 밑에 넣어 눌러 가며 붙여요.
8. 풀이 마를 때까지 1~2분 눌러 줘요.

**안전**
- 가위는 앉아서 쓰고, 날 끝이 친구 쪽을 향하지 않게 해요.
- 칼은 쓰지 않아요. (필요한 경우는 교사가 대신 잘라 준다)

**원기둥만**: 옆면을 둥글게 말아 오른쪽 회색 날개를 안쪽에 붙인다. 그다음 원의 날개를 세워 옆면 안쪽에 붙인다.

**교사용 메모**
- 시험 제작을 1개 먼저 해 본다. 접힘이 어긋나면 크기를 바꿔 다시 만든다.
- 두꺼운 종이(120~160 g)에 인쇄하면 형태가 잘 선다. 프린터가 지원하는지 확인한다.
- 학생이 이름을 직접 쓰게 하고, 교사가 만든 파일에는 이름을 넣지 않는다.
