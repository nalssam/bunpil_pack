# 학부모 설문 결과 분석

원안: 날쌤(몽당분필)의 학기말 학부모 설문 분석 스킬을 일반화했다. 규칙은 원안을 그대로 유지한다.

## 1. 역할과 목적

- 역할: 설문 담당 교사의 설문 분석 보조
- 목적: 설문 결과를 문항별 표와 개조식 요약 보고서 초안으로 정리한다
- 사용처 예: 교직원 협의회 보고, 차기 학기 교육과정 편성 참고

작업 폴더의 `CLAUDE.md` 또는 `AGENTS.md`가 있으면 먼저 읽어 학교급·문체를 반영한다. 없으면 설문 목적·기간·대상·모수(전체 학부모 수)만 짧게 묻는다.

## 2. 입력 파일

- 사용자가 올렸거나 지정한 폴더의 설문 결과 파일(xlsx / csv / 구글폼 내보내기 등)을 사용한다.
- 파일이 여러 개이면 모두 읽고, 중복 응답(동일 타임스탬프·동일 내용)은 1건으로 처리한다.
- 첫 행이 문항 텍스트인지, 별도 문항 안내 시트가 있는지 먼저 확인한다.
- 파일 구조가 불명확하면 작업을 멈추지 말고, 열 이름과 응답 예시 5건을 먼저 보여 준 뒤 진행한다.
- 연습용 가상 자료: `assets/sample_survey.csv`(합성 응답. 이름 열, 중복 1건, 자유응답 속 가상 실명 포함).

## 3. 개인정보 처리 (최우선)

학생 실명·학번·생년월일·주소·연락처·가족관계·사진 등 개인을 알아볼 수 있는 정보가 보이면 작업을 멈추고 '학생A'처럼 가명으로 바꾸자고 제안한다. 결과물에는 개인정보를 넣지 않는다.

- 응답자 이름, 학생 이름, 연락처, 이메일, 학번, 반·번호 등 식별 가능한 열은 분석 전에 삭제한다.
- 자유응답 문장 안에 교사 실명·학생 실명·특정 학급이 언급되면 "○○ 교사", "학생A", "○학년 ○반"으로 치환한다.
- 삭제·치환한 항목 목록을 보고서 말미에 한 줄로 기록한다. (예: "이름 1열, 연락처 1열 삭제, 자유응답 내 실명 3건 치환")
- 원본 파일은 수정하지 않고, 익명화된 사본을 만들어 작업한다.

## 4. 초안 규칙

모든 결과물은 초안이다. 첫머리에 '초안'을 적고, 협의회 보고·배포·외부 공개는 교사가 확인한 뒤 직접 한다. 데이터에 없는 수치는 만들지 않는다.

## 5. 문항별 정리표 작성 규칙

- 문항 순서는 설문지 원래 순서를 따른다.
- 표 구성: 문항 번호 / 문항 내용 / 응답 보기 / 응답 수 / 비율(%).
- 비율은 소수점 첫째 자리까지, 반올림 후 합계가 100.0이 되도록 조정한다(가장 큰 나머지를 가진 보기로 보정).
- 분모 기준
  - 단일 선택: 해당 문항 응답자 수(무응답 제외)
  - 복수 선택: 응답자 수 기준 비율과 응답 건수 기준 비율을 함께 표기
  - 무응답이 있으면 "무응답 n명"을 별도 행으로 표시
- 5점 척도 문항은 보기 순서를 "매우 그렇다 → 전혀 그렇지 않다"로 통일하고, 평균 점수(5점 만점)와 긍정 응답률(4~5점 합계)을 추가한다.
- 학년·학급 구분 열이 있으면 전체 표 뒤에 학년별 교차표를 추가한다. 학급별은 응답자 특정 우려로 생략한다.
- 응답자 수가 5명 미만인 셀은 비율 대신 "5명 미만"으로 표기한다.

## 6. 자유응답 요약 규칙

- 모든 자유응답을 먼저 한 줄씩 나열해 유사 내용끼리 묶은 뒤, 상위 3개 주제로 정리한다.
- 주제별로 기록한다: 주제명 / 해당 의견 수 / 대표 의견 2~3개(원문 요지 유지, 개인정보 제거).
- 3개 주제에 들어가지 않는 소수 의견은 "기타"로 한 줄 요약한다.
- 긍정 의견과 개선 요청을 구분해 표시한다.
- 의견 수는 "n건"으로 표기하고, 분석자 해석은 사실과 분리해 "해석" 항목에 따로 적는다.

## 7. 요약 보고서 초안 구성 (개조식, A4 2장 이내)

1. 설문 개요: 목적, 기간, 대상, 응답 수, 응답률(모수를 알 수 없으면 응답 수만)
2. 주요 결과: 문항별 핵심 수치 3~5개(긍정률 높은 문항, 낮은 문항)
3. 자유응답 주제 3가지
4. 시사점 및 차기 학기 반영 사항: 3~5개 항목
5. 익명화 처리 내역

- 문체: 개조식, 종결어미 "~함 / ~임" 통일.
- 표는 보고서에 최대 2개만 넣고 나머지는 정리표 파일 참조로 처리한다.

## 8. 결과물과 저장

- 저장 위치: 작업 폴더 안 `outputs/`(없으면 만든다). 채팅 전용 환경이면 대화에 표와 보고서를 제시한다.
- 파일 목록
  - `01_문항별_정리표.xlsx`(시트: 전체 / 학년별 / 자유응답 원문(익명) / 주제분류). xlsx를 만들 수 없는 환경이면 시트별 CSV.
  - `02_요약보고서_초안.md`(필요 시 한글 변환은 `hwpx-doc` 스킬 참고)
  - `00_익명화_사본.xlsx`(원본 대체용, 별도 요청이 없으면 생성)
- 파일명에 날짜를 붙인다(예: `_2026-09`).
- 완성 파일을 사용자에게 전달한다.

## 9. 작업 순서와 확인

1. 파일 읽기 → 열 구조 확인 → 개인정보 열 삭제
2. 문항별 집계 → 정리표 생성
3. 자유응답 분류 → 주제 3개 도출
4. 보고서 초안 작성
5. 검증: 문항별 응답 수 합계가 전체 응답자 수와 일치하는지, 비율 합계 100.0%, 개인정보 잔존 여부 재검색

검증 결과를 마지막에 5줄 이내로 보고한다.

## 10. 하지 말 것

- 원본 파일 수정
- 데이터에 없는 수치 추정이나 임의 생성
- 개별 응답자를 특정할 수 있는 표현(학급명 + 자유응답 결합 등)
- 보고서에 분석자 의견을 사실처럼 서술하는 것
- 생활기록부 서술형 문구 생성, 학생 개인별 평가

## 점검

- [ ] 식별 열을 삭제했고 자유응답 속 실명을 치환했으며, 결과물을 다시 검색해 잔존이 없는가
- [ ] 문항별 응답 수 합계가 전체 응답자 수와 일치하고 비율 합이 100.0인가
- [ ] 5명 미만 셀을 "5명 미만"으로 표기했는가
- [ ] 자유응답 주제가 3개 + 기타이고, 사실과 해석이 분리되어 있는가
- [ ] 보고서가 개조식(~함/~임) 2쪽 이내이며 '초안'이 표시되었는가
- [ ] 원본 파일은 그대로이고 결과가 `outputs/`에 있는가
