# 자산/소모품 구분 확인 질문

학교마다 기준이 다르다. 기준 금액·내구연한은 학교회계 예산편성 기본지침이나 물품관리 규정에서 확인한다. 아래 질문을 품목마다 쓰되 답을 대신 정하지 않는다.

1. 이 품목의 단가가 학교회계 지침의 자산(비품) 기준 금액 이상인가? (기준 금액: 확인 필요)
2. 1년 이상 사용할 수 있고 반복 사용하는 물건인가, 사용하면 없어지는 물건인가?
3. 낱개 단가는 기준 미만이지만 세트 구성품인가? (세트 단가로 볼지 확인)
4. 학교 물품관리 대장에 등록해야 하는가? 물품 관리 담당자는 누구인가?
5. 소프트웨어·구독형 서비스라면 기간과 라이선스 방식은 무엇이며, 별도 계약 절차가 필요한가?
6. 일정 금액 이상 구매에 요구되는 절차(견적서 수 등)가 있는가? (기준: 확인 필요)
7. 이 품목에 학생 개인정보를 처리하는 기능이 있는가? 있다면 학교의 소프트웨어 선정·개인정보 절차를 거쳤는가?

출력 예
| 품목 | 단가 | 질문 | 답(사용자 기입) |
|---|---|---|---|
| 무선 마우스 | 18,900원 | 1·2번 | |
