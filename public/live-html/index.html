살아있는 PPT를 여는 방법

슬라이드 안에서 퀴즈를 누르고 슬라이더를 움직이는 PowerPoint 파일입니다. 처음 여는 컴퓨터에서는 노란 “추가 기능 오류” 줄이 뜹니다. 고장이 아니라 이 컴퓨터에 아직 등록하지 않았다는 뜻입니다.

먼저 알아 둘 것

  • 슬라이드 쇼에서 눌러 쓰려면 Windows의 Microsoft 365 PowerPoint(최신 채널에서 확인)가 필요합니다. Office LTSC 2021·2024는 편집 화면에서만 눌러집니다. 표 보기
  • 발표할 때 인터넷이 연결되어 있어야 합니다.
  • 안 되면 함께 받은 브라우저용 HTML(deck-browser.html)을 브라우저로 엽니다. 방법 보기

1. 등록하기 (컴퓨터마다 한 번)

발표할 컴퓨터에서 이 페이지를 열면 명령을 복사해 붙여넣을 수 있습니다.
https://nalssam-bunpil.vercel.app/live-html/

Windows

시작 메뉴에서 PowerShell을 찾아 열고, 아래 한 줄을 붙여넣은 뒤 Enter를 누릅니다.

powershell -NoProfile -Command "irm https://nalssam-bunpil.vercel.app/live-html/register.ps1 | iex"

Mac

터미널을 열고, 아래 한 줄을 붙여넣은 뒤 Enter를 누릅니다. Mac PowerPoint에서 되는지는 아직 확인하지 못했습니다.

curl -fsSL https://nalssam-bunpil.vercel.app/live-html/register.sh | sh

“등록했습니다”라고 나오면 PowerPoint를 완전히 종료했다가 다시 열고 파일을 엽니다. 위쪽에 “제한된 보기” 줄이 보이면 편집 사용을 누릅니다.

현재 사용자 계정에만 등록되고 관리자 권한을 쓰지 않도록 만들었습니다. 명령이 무엇을 하는지 먼저 보고 싶으면 register.ps1(Windows)이나 register.sh(Mac) 주소를 열어 내용을 읽어 볼 수 있습니다. 프로그램을 설치하지 않고, 주소가 적힌 작은 설정 파일(manifest.xml) 하나를 내려받아 둡니다. Windows에서는 그 위치를 레지스트리에 한 줄 적습니다.

2. 어느 PowerPoint에서 되나

PowerPoint편집 화면슬라이드 쇼전체 화면
Microsoft 365구독형 최신 채널 16.0.20625눌러짐눌러짐
Office LTSC 2024기관용 고정판 16.0.17932눌러짐화면만 보임
Office LTSC 2021기관용 고정판 16.0.14334눌러짐화면만 보임
Office 2019볼륨판 16.0.10417그림과 안내 줄그림과 안내 줄
  • 내 PowerPoint 확인: 파일 → 계정 → “제품 정보”에 “Microsoft 365”라고 나오면 구독형입니다.
  • 볼륨판: 학교·기관이 한꺼번에 사서 설치한 Office입니다.
  • 화면만 보임: 편집 화면에서 해 둔 상태 그대로 보이고, 화면 속 단추는 눌러지지 않습니다. 클릭하면 다음 장으로 넘어갈 수 있습니다. LTSC 2024에서는 편집 화면에서 열어 보지 않은 장이 희거나 검게 나올 수 있습니다.
  • 창으로 띄우는 쇼와 읽기용 보기에서는 Microsoft 365에서도 화면만 보입니다(LTSC 2021에서는 흰 화면도 있었습니다).

Windows에서, 그래픽 카드가 없는 시험용 컴퓨터로 확인한 결과입니다. 그래픽 카드가 있는 LTSC 컴퓨터에서 달라지는지는 모릅니다. 확인하지 못한 것: 다른 업데이트 채널이나 더 오래된 Microsoft 365(기관이 업데이트를 늦춘 곳은 발표 전에 슬라이드 쇼로 한 번 눌러 보세요), Mac PowerPoint, 웹용 PowerPoint, 하나씩 따로 산(볼륨판이 아닌) Office 2021·2024, Office 2016, 발표자 보기, 펜·레이저 포인터, 터치 화면·전자칠판, 휴대폰·태블릿, 한쇼, 구글 슬라이드, PDF·인쇄·동영상 내보내기(미리보기 그림으로 나올 것으로 봅니다).

3. 이런 화면이 보이면

추가 기능 오류 — 이 추가 기능은 더 이상 사용할 수 없습니다. 배포 중에 삽입된 추가 기능만 Visual Studio에서 디버깅하는 중에 사용할 수 있습니다. … 에 배포하고 다시 삽입하세요. [닫기]

이 컴퓨터에 등록하지 않았다는 뜻입니다. 그림은 노란 줄 밑에 그대로 있습니다. 1번대로 등록하고 PowerPoint를 완전히 종료했다가 다시 엽니다. (LTSC 2024의 슬라이드 쇼에서는 그림 대신 흰 화면이었습니다.)

추가 기능 오류 — 추가 기능을 로드할 수 없습니다. 네트워크 및/또는 인터넷 연결 여부를 확인해 보세요. 온라인으로 돌아온 경우 "다시 시도"를 클릭하세요. [다시 시도] [닫기]

등록은 됐지만 추가 기능 페이지를 불러오지 못했습니다. 이때는 그림 대신 흰 화면입니다. 인터넷 연결을 확인하고 다시 시도를 누릅니다. 계속되면 학교망이 nalssam-bunpil.vercel.app을 막는지 정보 담당 선생님께 확인합니다.

이 PowerPoint의 웹 엔진이 오래되어 HTML을 실행할 수 없습니다. Microsoft 365 또는 Office 2021 이상에서 열어 주세요.

그림 아래에 이 검은 줄이 보이면 오래된 PowerPoint입니다(Office 2019 볼륨판에서 확인). 이 컴퓨터에서는 실행되지 않습니다. 그림으로 발표하거나 브라우저로 엽니다. 안내 문구와 달리, 슬라이드 쇼에서 눌러 쓰려면 Microsoft 365가 필요합니다.

편집 화면에서는 눌러지는데 슬라이드 쇼에서는 안 된다

Office LTSC 2021·2024에서 그렇습니다(2번 표). 쇼에서 눌러 써야 하면 브라우저로 엽니다.

4. 발표할 때 Microsoft 365에서 확인

  • 넘기기: ← → PageUp PageDown 키를 씁니다. 화면 속에 넘기기 단추가 있으면 그것도 됩니다. 살아있는 장에서는 클릭해도 넘어가지 않습니다.
  • 글자 입력칸 안에서는 ← →가 글자 사이를 움직입니다. PageDown으로 넘기거나, 빈 곳을 한 번 누른 뒤 넘깁니다.
  • 끝내기: 화면 속을 누른 뒤에는 Esc를 두 번 누릅니다.
  • 눌러 둔 것은 남습니다. 편집 화면에서 펼친 정답은 쇼에서도 펼쳐져 있습니다. 파일을 닫았다가 다시 열면 처음으로 돌아갑니다.
  • 저장하면 미리보기 그림이 그 순간의 화면으로 바뀝니다. 정답을 펼친 채 저장하면 그림에 정답이 남습니다.

5. 브라우저로 발표하기 어느 컴퓨터에서나

  1. pptx와 함께 받은 deck-browser.html(그림·글자가 한 파일에 합쳐진 것)을 Edge나 Chrome으로 엽니다.
  2. F11을 눌러 전체 화면으로 만듭니다.
  3. ← → 키로 넘깁니다.

등록도 Microsoft 365도 필요 없습니다. deck-browser.html이 없으면 파일을 만든 분께 받으세요. (그림이 따로 있는 deck.html만 받으면 그림이 깨질 수 있습니다.)

6. 지우기

Windows

powershell -NoProfile -Command "irm https://nalssam-bunpil.vercel.app/live-html/unregister.ps1 | iex"

Mac

curl -fsSL https://nalssam-bunpil.vercel.app/live-html/register.sh | sh -s -- --remove

실행한 뒤 PowerPoint를 다시 열면 적용됩니다.

개인정보

슬라이드의 HTML은 PowerPoint 파일 안에 들어 있습니다. 추가 기능 페이지는 그것을 꺼내 화면에 그릴 뿐, 내용을 이 사이트로 보내거나 저장하지 않습니다. 페이지를 불러올 때 이 사이트와 Microsoft 서버에 일반적인 접속 기록은 남습니다. 믿을 수 있는 사람이 만든 파일만 여세요.
