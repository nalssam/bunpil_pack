살아있는 PPT를 여는 방법

슬라이드 안에서 퀴즈를 누르고 슬라이더를 움직일 수 있는 PowerPoint 파일을 받으셨나요? 화면이 그림으로만 보인다면, 이 컴퓨터에 Live HTML 추가 기능을 한 번 등록하면 됩니다.

1. 등록하기 (한 번만)

Windows

시작 메뉴에서 PowerShell 또는 명령 프롬프트를 열고 아래 한 줄을 붙여넣어 실행합니다.

powershell -NoProfile -Command "irm https://nalssam-bunpil.vercel.app/live-html/register.ps1 | iex"

Mac

터미널을 열고 아래 한 줄을 붙여넣어 실행합니다.

curl -fsSL https://nalssam-bunpil.vercel.app/live-html/register.sh | sh

그다음 PowerPoint를 완전히 종료했다가 다시 열고 파일을 엽니다. 위쪽에 "보호된 보기" 노란 줄이 보이면 편집 사용을 누릅니다.

등록은 현재 사용자 계정에만 적용되고 관리자 권한이 필요 없습니다. 프로그램을 설치하지 않고, 주소가 적힌 작은 설정 파일(manifest.xml) 하나를 PowerPoint가 찾을 수 있는 곳에 둡니다.

2. 필요한 것

  • Microsoft 365 또는 Office 2021 이상의 PowerPoint (Windows·Mac). Office 2016·2019에서는 그림만 보입니다.
  • 발표할 때 인터넷 연결.
  • 휴대폰·태블릿 앱, 한쇼, 구글 슬라이드, PDF에서는 그림으로 보입니다.

3. 그래도 움직이지 않을 때

보이는 것할 일
그림만 보인다위 1번을 실행했는지, PowerPoint를 완전히 껐다 켰는지 확인합니다.
"추가 기능을 로드할 수 없습니다"인터넷 연결을 확인하고 다시 시도를 누릅니다. 학교망이 이 사이트를 막는지 정보 담당 선생님께 확인합니다.
"웹 엔진이 오래되어…"Microsoft 365 또는 Office 2021 이상이 깔린 컴퓨터에서 엽니다.
슬라이드 쇼에서만 빈 화면파일 → 옵션 → 고급 → "슬라이드 쇼 하드웨어 그래픽 가속 사용 안 함"을 켭니다.
발표자 보기에서 눌리지 않는다청중이 보는 화면에서 누릅니다.

4. 지우기

powershell -NoProfile -Command "irm https://nalssam-bunpil.vercel.app/live-html/unregister.ps1 | iex"
curl -fsSL https://nalssam-bunpil.vercel.app/live-html/register.sh | sh -s -- --remove

개인정보

슬라이드의 HTML은 PowerPoint 파일 안에 들어 있습니다. 이 사이트의 추가 기능 페이지는 그 HTML을 꺼내 화면에 그릴 뿐, 내용을 어디로도 보내거나 저장하지 않습니다. 믿을 수 있는 사람이 만든 파일만 여세요.
