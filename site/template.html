    터미널 열기

    키보드의 ⊞ Windows 키를 누르고 PowerShell을 입력한 뒤 Windows PowerShell을 클릭합니다. 관리자로 실행하지 않아도 됩니다. PS C:\Users\이름> 같은 줄이 보이면 준비 완료입니다.

    ⌘ Command + Space를 누르고 터미널을 입력한 뒤 Enter를 누릅니다. 이름@Mac ~ % 같은 줄이 보이면 준비 완료입니다.

    명령 프롬프트(검은 창)를 열었어요

    명령 프롬프트(C:\>)가 아니라 PowerShell(PS C:\>)이어야 합니다. 앞에 PS가 보이는 창을 여세요.

    • Claude Code(없을 때만, Anthropic 공식 설치 프로그램)

    • 분필팩 5종과 날쌤 추천 teacher 묶음(한글 HWPX 도구 3종, 발표 자료 엔진, 문서 변환, 브라우저 자동화, 웹 수집, 하네스 팩토리)

    Git을 설치할 때 "이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?" 창이 뜨면 예를 누르세요. 거절하면 Git이 필요한 일부 추천 도구(한글 편집 엔진, 하네스 팩토리 등)만 건너뛰고, 나중에 같은 줄을 다시 실행하면 채워집니다.

    Git이 없는 맥이면 "명령어 개발자 도구를 설치하겠습니까?" 창이 뜹니다. 설치를 누르고, 설치가 끝나면 같은 줄을 한 번 더 실행하세요. 그사이 Git이 필요 없는 항목은 먼저 설치됩니다.

    초록색 [v]✓ 줄이 이어지다가 분필팩 설치 완료가 보이면 끝입니다.

    빨간 줄이 있거나 중간에 멈췄어요

    같은 줄을 한 번 더 실행하세요. 이미 설치된 것은 건너뛰고 빠진 것만 채웁니다.

    학교 인터넷에서 내려받기가 막히면 휴대폰 핫스팟으로 연결해 다시 실행해 보세요.

    'irm'은(는) 내부 또는 외부 명령...이 보이면 명령 프롬프트에 붙여넣은 것입니다. PowerShell을 여세요.

    새 창에서 Claude 시작하고 로그인

    설치한 명령을 찾을 수 있도록 지금 창을 닫고 새 PowerShell터미널 창을 엽니다. 그다음 작업 폴더를 만들고 Claude를 실행합니다.

    PS>mkdir -Force ~\분필작업 > $null; cd ~\분필작업; claude
    %mkdir -p ~/분필작업 && cd ~/분필작업 && claude
    • 처음 실행하면 화면 색을 고르고, 로그인 방법에서 Claude 구독 계정을 고릅니다.
    • 브라우저가 열리면 로그인하고 승인한 뒤 터미널로 돌아옵니다.
    • "이 폴더를 믿을까요?"라고 물으면 예를 고릅니다.

    앞으로는 분필작업 폴더에 자료를 넣고 그 폴더에서 claude를 실행하면 됩니다.

    한 번 만들어 두면 이후 모든 요청이 내 교실 기준으로 맞춰집니다. 바뀐 점이 생기면 다시 실행하면 됩니다.

분필팩과 함께 설치

분필팩을 설치하면서 날쌤팩도 넣습니다. Claude Code가 있으면 날쌤팩을 --claude로 설치하고, 겹치는 도구는 날쌤팩의 고정 버전을 씁니다.

%curl -fsSL {{SITE}}/install.sh | sh -s -- --nalssam

macOS·Linux 터미널에서 실행합니다. Windows는 WSL2 Ubuntu 터미널에서 실행하며, 이때는 WSL 안의 Claude Code·Codex에 설치됩니다.

날쌤팩만 설치

Claude Code용 — 스킬과 네이티브 플러그인까지

%bash -c "$(curl -fsSL https://raw.githubusercontent.com/nalssam/nalssam-pack/v1.0.1/install.sh)" -- --claude

Codex용

%bash -c "$(curl -fsSL https://raw.githubusercontent.com/nalssam/nalssam-pack/v1.0.1/install.sh)"
  • 설치가 끝나면 새 터미널에서 nalssam-pack doctor --verify-mcp로 실제 연결을 점검합니다.
  • 계정이 따로 필요한 것: 나레이션(ElevenLabs), 영상 음성 인식(Gemini 등), Google Cloud 데이터 플러그인, Adobe After Effects. 설치가 끝난 것과 계정이 연결된 것은 다릅니다.
  • --claude는 개발용 플러그인(개발 워크플로 90여 종, Google Cloud 데이터 도구 등)까지 켭니다. 필요 없는 플러그인은 Claude Code에서 /plugin으로 끌 수 있습니다.
  • 날쌤팩에만 있는 도구는 설치되는 것의 nalssam 묶음에서 볼 수 있습니다. 자세한 안내: GitHub nalssam/nalssam-pack

    문제 해결과 자주 묻는 질문

    'irm'은(는) 내부 또는 외부 명령이 아니라고 나와요

    명령 프롬프트(cmd)에 붙여넣은 경우입니다. 시작 메뉴에서 PowerShell을 열고 다시 붙여넣으세요. 창 맨 앞에 PS가 보여야 합니다.

    "이 시스템에서 스크립트를 실행할 수 없으므로…"가 나와요

    한 줄 설치(irm … | iex)는 파일을 저장하지 않아 대부분 그대로 됩니다. 이 메시지가 codex나 npm을 실행할 때 나온다면 PowerShell에서 아래를 한 번 실행하세요.

    PS>Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

    학교에서 관리하는 PC라 바뀌지 않으면 정보 담당 선생님께 문의하세요.

    claude 또는 codex 명령을 찾을 수 없다고 나와요

    설치 직후에는 터미널 창을 닫고 새로 열어야 새 명령을 찾습니다. 새 창에서도 안 되면 설치 한 줄을 다시 실행하세요.

    빨간 [x] 또는 ✗ 줄이 보여요

    같은 한 줄을 다시 실행하세요. 설치된 것은 건너뛰고 실패한 것만 다시 시도합니다. 계속 실패하면 그 줄을 캡처해 문의해 주세요.

    학교 인터넷에서 내려받기가 안 돼요

    학교 방화벽이 막는 경우가 많습니다. 휴대폰 핫스팟에 연결해 다시 실행하거나, 집에서 분필팩 zip을 받아 USB로 옮긴 뒤 압축을 풀고 더블클릭으로 설치하세요. 분필팩 5종은 인터넷 없이도 설치되고, 추천 도구는 인터넷이 필요합니다.

    업무망 PC에 설치해도 되나요?

    업무망 PC는 인터넷이 막혀 있고 프로그램 설치가 제한되며, 학교마다 규정이 있습니다. 인터넷망 PC나 개인 기기에 설치하세요. 업무망 자료를 옮길 때는 학교 규정을 따릅니다.

    Windows에서 "Windows의 PC 보호" 창이 떠요 (zip 더블클릭 설치)

    인터넷에서 받은 파일이라 뜨는 확인 창입니다. 추가 정보 → 실행을 누르세요. 걱정되면 zip 대신 PowerShell 한 줄 설치를 쓰면 됩니다.

    맥에서 Install-Mac.command가 열리지 않아요

    파일을 오른쪽 클릭해 열기를 누르세요. 그래도 막히면 시스템 설정 → 개인정보 보호 및 보안에서 그래도 열기를 누릅니다. 가장 쉬운 방법은 터미널 한 줄 설치입니다.

    Claude 앱에 플러그인 메뉴가 없어요

    플러그인은 Claude 유료 요금제(Pro·Max·Team·Enterprise)에서 쓸 수 있습니다. 무료로 시작하려면 ChatGPT Codex 탭을 따라 하세요.

    일부 기능이 회색으로 보여요

    웹 채팅은 자동 점검(훅)과 서브에이전트를 쓰지 않아 회색으로 보입니다. 정상입니다. Cowork나 Claude Code에서는 모든 기능이 작동합니다.

    Codex에서 개인정보 가드가 작동하지 않아요

    Codex 대화창에서 /hooks를 입력하고 분필 가드를 신뢰(trust)하세요. 분필팩을 업데이트하면 다시 신뢰해야 합니다.

    가짜 번호에도 경고가 떠요

    가드는 번호의 형식만 보고 판단합니다. 실제 개인정보가 아니면 그대로 진행해도 됩니다. 주민등록번호 형식(000000-0000000)은 입력 자체를 막습니다.

    가드를 잠시 끄고 싶어요 (수업 예시 작업 등)

    환경변수 BUNPIL_GUARD=off를 주고 실행하거나, 잠시 분필 시작 팩을 비활성화하세요. 작업이 끝나면 다시 켜 두세요.

    브라우저 자동화 첫 실행이 느려요

    처음 한 번 브라우저 구성 요소를 내려받기 때문입니다. 한 번만 기다리면 이후에는 빠릅니다.

    설치하면 컴퓨터에 무엇이 바뀌나요?
    • 홈 폴더의 .bunpil 폴더에 분필팩을 둡니다. Node.js를 관리자 권한 없이 설치할 때도 이 폴더(.bunpil/node)를 씁니다.
    • Claude Code·Codex에 분필팩과 추천 도구의 플러그인·MCP 연결을 등록하고, 추천 스킬은 각 프로그램의 사용자 스킬 폴더에 복사합니다.
    • 없을 때만 Claude Code·Codex·Node.js·uv·Git을 공식 설치 프로그램으로 설치합니다. Windows에서 Git·Node.js를 winget으로 설치할 때는 확인 창이 뜹니다.
    • 새 창에서도 명령을 찾도록 PATH를 남깁니다. 맥·리눅스는 ~/.bunpil/env 파일을 만들고 셸 설정 파일(~/.zshrc, ~/.bashrc, ~/.bash_profile, ~/.profile 중 있는 것, 맥은 ~/.zshrc가 없으면 새로 만듦)에 # bunpil-path 표시가 붙은 한 줄을 더합니다.Windows는 사용자 PATH에 폴더를 더합니다(기존 항목은 그대로 둠).
    • Codex를 npm으로 설치한 경우에만, PowerShell에서 codex 명령이 실행되도록 현재 사용자의 실행 정책을 RemoteSigned로 바꿉니다. 되돌리기: Set-ExecutionPolicy -Scope CurrentUser Undefined

    지우기 명령은 분필팩 5종과 .bunpil/bunpil-pack 폴더를 지우고, 나머지는 그대로 둔 채 직접 지우는 방법을 알려 줍니다.

    분필팩과 날쌤팩은 무엇이 다른가요?

    분필팩은 모든 선생님이 Windows·맥에서 바로 쓰는 교사 업무 도구 모음이고, 날쌤팩은 날쌤의 전체 작업 환경(영상·모션·발표·분석·개발 도구, 고정 버전)입니다. 날쌤팩은 macOS·Linux·WSL2에서만 설치되고 수 GB가 필요합니다. 날쌤팩 안내를 보세요.

    수업 슬라이드는 어떤 도구로 만드나요?

    teacher 묶음의 발표 자료 엔진(pptx-maker)이 연결돼 있으면 "수업 슬라이드 만들어줘"라고 할 때 그 엔진으로 .pptx를 만들고 디자인 점검·채점까지 합니다. 발표할 PC에 테마 글꼴이 없으면 pptx-maker fonts install로 무료 글꼴을 설치하세요.

    크롬(지금 열어 둔 탭)과 연결하려면?

    Claude Code에서만 됩니다. 크롬 웹스토어에서 Claude 확장 프로그램을 설치하고 같은 계정으로 로그인한 뒤, 터미널에서 claude --chrome으로 시작하세요. 늘 켜 두려면 대화창에서 /chrome → Enabled by default를 고릅니다. 유료 요금제(Pro 이상)가 필요하고 WSL에서는 되지 않습니다. 확장 설치는 명령으로 대신할 수 없어 설치 스크립트는 안내만 합니다. Codex에서는 teacher 묶음의 브라우저 자동화(Playwright)를 쓰세요. 공식 안내

    Firecrawl·Perplexity·Glif는 계정이나 돈이 드나요?

    Firecrawl(웹사이트 내용 수집)은 키 없이 쓰는 무료 구간으로 연결합니다. 수집·검색·읽기 3가지가 되고 사용량 제한이 있습니다. Perplexity(최신 뉴스·문서 검색)는 유료 API 키가 있어야 해서, 키가 있을 때만 연결합니다. console.perplexity.ai에서 키를 받아 curl -fsSL {{SITE}}/claude.sh | PERPLEXITY_API_KEY=받은키 sh$env:PERPLEXITY_API_KEY="받은키"; irm {{SITE}}/claude.ps1 | iex처럼 다시 실행하세요(키는 Claude Code·Codex 설정 파일에 저장됩니다). Glif(이미지·영상 AI, creator 묶음)는 Glif 계정으로 로그인해야 하고 만들 때 크레딧을 씁니다. Claude Code는 /mcp → glif, Codex는 codex mcp login glif로 로그인합니다.

    인스타그램 스킬은 어떻게 쓰나요?

    creator 묶음에 들어 있는 instagram-agent-skill(무료, MIT)입니다. 아이디어 한 줄을 주면 훅 3개와 릴스 대본, 화면 자막, 캡션까지 써 줍니다. Claude Code에서 /ig-reel처럼 부르거나 "릴스 대본 써줘"라고 하세요. 인스타 계정을 연결하지 않으며 올리기는 직접 합니다. 학생 얼굴·이름이 나오는 게시물은 학교 지침을 먼저 확인하세요.

    영상 만들기(Cinetic·Prompt Motion·수업 영상)는 어떻게 쓰나요?

    수업 설명 영상은 분필 수업자료 팩의 수업 영상 스킬에 "분수의 덧셈을 설명하는 1분 영상 만들어줘"처럼 말하면 됩니다. 스토리보드(장면별 화면과 대본)를 먼저 보여 드리고, 승인하면 수학·과학 개념 애니메이션(Manim)과 한국어 음성(edge-tts)으로 만듭니다. 이 두 도구는 영상을 처음 만들 때 필요한 만큼만 설치를 물어보고 설치합니다.

    소개·출시 영상은 creator 묶음의 Cinetic 스킬이 문장 한두 줄로 소리 포함 영상을 만듭니다. bash 스크립트라 macOS·Linux·WSL2에서만 되고, Windows 기본 터미널에서는 설치를 건너뜁니다. 영상을 만들 때 ffmpeg 6 이상, Node 22 이상, Python 3.11 이상이 필요합니다. 맥에서는 brew install ffmpeg node python, Windows에서는 PowerShell에서 winget install Gyan.FFmpeg처럼 설치합니다.

    Prompt Motion(prompt-motion.com)은 클로드로 만든 모션 영상 234개와 프롬프트 원문을 모아 둔 사이트입니다. 설치할 것은 없고, 마음에 드는 영상의 프롬프트를 Copy해서 붙여넣으세요. 영상과 프롬프트는 각 원작자의 것이니 그대로 다시 올리지 마세요.

    edge-tts는 대본 글자를 인터넷 음성 서비스로 보냅니다. 학생 이름·사진 등 개인정보가 든 글은 넣지 마세요. 만든 영상에는 AI로 만들었다는 표시를 권합니다.

    학생도 쓸 수 있나요? 생활기록부 문구도 써 주나요?

    분필팩은 교사의 수업 준비와 행정 업무용입니다. 학생이 직접 쓰는 도구가 아닙니다. 생활기록부 서술형 문구는 만들지 않습니다(2026 기재요령).

    맞는 질문이 없습니다. 다른 낱말로 찾아보세요.
